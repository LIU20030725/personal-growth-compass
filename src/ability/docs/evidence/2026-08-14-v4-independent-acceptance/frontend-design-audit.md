# Frontend Design Audit：能力模块 V4

范围：能力模块页面、画布、线性路线、节点详情、弹窗与三档响应式。审核了 V4 差异中的 TSX/CSS、六张新截图和浏览器语义结果。

> 安装包未包含技能正文引用的 `../../../references/heuristics.md` 与 `patterns.md`；本报告按 SKILL.md 内完整列出的 15 项原则执行并记录该依赖缺口。

| # | 原则 | 结论 |
|---|---|---|
| 1 | 系统状态可见 | 通过：进度、状态、候选数量、撤销/重做禁用和保存失败均可见。 |
| 2 | 匹配真实世界 | 通过：使用“阶段、技能、掌握标准、成果、资源”，没有暴露内部 Schema 术语。 |
| 3 | 用户控制与自由 | 通过：空白关闭、Esc、撤销/重做、自动布局复位；焦点恢复缺陷已在 `68fb960` 修复。 |
| 4 | 一致性与标准 | 通过：按钮、菜单、弹层、冷白/鼠尾草/柔黄和硬朗边框保持一致。 |
| 5 | 错误预防 | 通过：掌握门禁、阶段非空时禁止删除、依赖环校验、URL 校验均有自动化覆盖。 |
| 6 | 识别优于回忆 | 通过：“下一步 · N”、节点加号、阶段空态和快捷键面板使动作可发现。 |
| 7 | 灵活与高效 | 通过：直接操作、画布快捷键与移动线性路线并存，Tab 不被劫持。 |
| 8 | 美观与极简 | S2：画布工具条七个同级动作密度偏高；不阻塞，本轮接受。 |
| 9 | 错误恢复 | 通过：领域/画布保存失败不移动历史指针；失败拖动回滚缺陷已修复。 |
| 10 | 帮助与文档 | 通过：画布内提示和快捷键弹层提供上下文帮助。 |
| 11 | 可供性与指示 | 通过：按钮使用真实 button、图标带文字/名称，节点选中有边框、工具条和状态文字。 |
| 12 | 结构 | 通过：阶段、节点详情、技能库和画布边界清晰；移动端改用路线。 |
| 13 | 无障碍 | 通过：axe serious/critical 0；键盘、焦点陷阱、恢复和 44px 移动触控门禁通过。 |
| 14 | 可感知性 | 通过：状态不只靠颜色，进度有数值，主/辅助/阶段关系有形态差异。 |
| 15 | 容错与宽容 | 通过：V2 与缺失 `phasePositions` 安全读取，损坏偏好和非法坐标降级。 |

## 设计系统一致性

- 冷白底、鼠尾草完成态、柔黄选中/主操作保持用途单一。
- 画布不是卡片墙：阶段是容器，节点是可操作对象，详情是证据面板。
- 语义与视觉同步：`aria-pressed` 对应激活样式，禁用按钮可见，状态同时有文字。
- 长名称由换行/截断策略控制；极长阶段标题的几何保持有限值，自动化已覆盖。
