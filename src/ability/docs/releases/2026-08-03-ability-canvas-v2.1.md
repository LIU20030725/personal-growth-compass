## 本次变更

1. 主依赖边改为自定义正交边。同一父节点的直接子节点共享固定 `branchX` 母线，路径统一为“父节点右侧中心 → 分支母线 → 子节点左侧中心”，拐角半径 9px，箭头与节点边框保留 12px 间距。
2. 主依赖使用实线，辅助依赖使用虚线；箭头颜色跟随边颜色，避免选中状态下入口颜色漂移。
3. 自动布局采用 16px 几何网格：列距 272px、同级行距 144px、节点 176×80px；并行组外框、标题、节点和母线使用同一网格体系。
4. 拖拽结束自动吸附到 16px 网格，持久化保存吸附后的坐标；“重新自动布局”清空手动位置并恢复深度列对齐。
5. 保留 React Flow 的移动、缩放、定位、小地图和撤销交互；修复快速连续新增、多层新增以及删除后撤销时节点测量信息丢失、SVG 边偶发消失的问题。
6. 视觉调整为中性暖白画布、淡点阵、弱化未选节点与工具条阴影；黄色仅用于选中态和主要操作，保留硬朗编辑器风格。
7. 手机端继续使用线性路线，不在 390px 视口强塞画布；40 节点数据仍可浏览和定位。

## 已知限制

1. 桌面视觉基准当前只在 Windows Chromium 保存；其他操作系统的字体与 SVG 抗锯齿可能需要独立基准。
2. 用户手动拖拽后允许节点偏离自动深度列，这是自由布局的预期行为；使用“重新自动布局”可恢复完全对齐。
3. 390×844 及更窄视口默认展示线性路线，不提供完整画布编辑；复杂关系编辑仍建议使用桌面端。
4. 辅助依赖保持独立虚线语义，不参与同父级主分支母线合并；主技能树结构以主依赖为准。
