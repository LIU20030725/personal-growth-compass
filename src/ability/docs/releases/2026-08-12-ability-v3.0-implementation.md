## 本次变更

1. 数据状态升级为 schema v2，新增阶段时长/计划日期、节点必修属性、学习资源与节点资源关联；旧版 masteryNote 和 taskLinks 仅保留兼容，不再出现在新 UI。
2. 能力模块收敛为“技能库 → 当前技能树 → 阶段路线 → 节点详情”的主路径，技能库上移为最多 6 张紧凑横向卡片，常用筛选仅保留“全部 / 下一步 / 已掌握”。
3. 结构操作统一进入“编辑技能树”模式。浏览模式不显示新增、删除、拖动、连线、撤销、重排和节点归档入口，快捷键也只在编辑模式且画布明确聚焦时生效。
4. 阶段成为画布一级结构：所有阶段（包括空阶段）都以独立列展示，阶段、节点、并行组和分支母线共用 16px 网格；空阶段可就地添加第一个节点。
5. 节点详情按“掌握标准 → 学习资源 → 真实成果”排列。资源仅在打开节点后显示，支持链接收藏、URL 去重、跨节点复用、编辑、解除关联和安全删除。
6. 掌握判定要求“全部标准已满足”或“存在真实成果”，空证据不允许直接掌握。
7. 线性路线改为紧凑阶段列表；390px 默认使用线性视图，节点详情以可关闭的底部面板出现，不在手机端开放画布结构编辑。

## 数据迁移与兼容

- 沿用存储键 `dice-life.ability.v1`，读取时同时接受 schema v1/v2，v1 自动补字段迁移为 v2。
- 旧技能树、阶段、节点、依赖、并行组、掌握说明、任务关联与成果均保留；旧任务和 masteryNote 只是不再进入当前界面。
- 新增资源 URL 使用规范化值全局去重；从节点移除只删除关联，资源仍被其他节点引用时禁止删除原件。
- `AbilityModule.taskStorage` 暂保留为可选兼容参数，但 V3 不再消费任务系统数据。

## 已知限制与待验收项

1. 本版资源仅支持 HTTP/HTTPS 链接和手工录入，不含文件上传、内置阅读器、失效链接巡检或自动抓取元数据。
2. AI 仍是后续扩展：未提供推荐、自动拆树或学习计划 UI；schema 已预留来源和推荐说明字段，API/Skill 约束继续由后续版本接入。
3. 画布手动拖动允许节点暂时越出阶段视觉边界；重新自动布局会恢复阶段列对齐。
4. 资源库目前以内嵌节点选择器复用，不提供独立的全局资源管理页面。
5. 本归档只记录实现级检查，不代表最终验收通过。待总控下发独立测试与验收清单后，再执行全量 E2E、axe、视觉截图、键盘走查和缺陷修复。
