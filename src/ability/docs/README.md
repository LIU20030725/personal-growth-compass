# 能力模块资料目录

能力模块后续产生或变更的产品、设计、测试资料统一存放在本目录，不再新增到项目全局 `docs/`。

- `specs/`：产品规格、交互规则与数据规范
- `plans/`：具体实施计划、迭代拆分与验收标准
- `research/`：竞品、工具与用户研究
- `audits/`：Bug、产品、UX、UI、可访问性与性能审计报告
- `releases/`：连续版本归档、变更摘要、已知限制与验收证据

文件名使用 `YYYY-MM-DD-主题.md`。与代码行为有关的结论应附对应测试或验收证据。
