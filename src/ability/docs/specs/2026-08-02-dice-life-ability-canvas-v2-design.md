# Dice Life 能力技能树画布 V2 设计规格

## 1. 产品定位

能力模块用于建设数量不限的主技能、副技能与探索技能。用户是内容主体，手动创建、编辑和维护技能树；AI 只作为后续可选扩展，通过主页面设置中配置的第三方 API 和后台 Skill 规范生成建议草稿，初版不提供 AI 功能。

技能树同时承载三类信息：

- 学习结构：技能之间的主父级、串行、并行和汇合关系；
- 当前状态：未开始、进行中、已掌握；
- 成长证明：用户手动填写的成果、关联任务和掌握标准。

## 2. 视觉与布局原则

- 整体从左向右生长，基础在左，进阶和目标在右；
- 串行关系水平推进，并行关系垂直排列；
- 主树采用共享主干、直角折线和常显小箭头；
- 并行节点放入淡黄色半透明“可并行”容器；
- 并行后的共同下一步使用分叉—汇合结构；
- 辅助关系默认全部显示为低对比虚线，同方向关系自动共用线束；
- 选中节点时，高亮相关连线，其他连线降低对比度；
- 连线不得穿过节点正文，不用大面积装饰或游戏闯关视觉。

## 3. 关系模型

### 3.1 主父级

每个节点最多有一个主父级。主父级决定自动布局层级、子树所有权、折叠范围、删除范围和拖拽重新挂载后的结构。

同一个父节点连续点击 `+` 创建的节点均为下一层同级子节点；多个同级子节点在视觉和语义上视为可并行。

### 3.2 辅助关系

用户从节点连接点手动画出的关系为辅助建议关系：

- 只表示推荐学习顺序或相关性；
- 不改变节点主父级；
- 不影响删除范围和折叠范围；
- 不锁定节点，也不阻止用户开始任何技能。

### 3.3 并行汇合

按住 `Shift` 多选同一父级下至少两个节点后，浮动工具栏显示“汇合到下一步”。执行后建立可并行分组并创建共同下一步。删除某个并行分支时只删除该分支，后续节点保留；只剩一个有效分支时自动退化为普通串行关系。

## 4. 节点状态

只保留三种用户可见状态：

- `available`：未开始；
- `in_progress`：进行中；
- `mastered`：已掌握。

依赖关系不再派生 `locked` 状态。前序未完成时可以显示非阻塞提醒，但用户始终可以开始或更新任意节点。

## 5. 画布交互

### 5.1 导航

- 拖动空白区域平移画布；
- 鼠标滚轮平移画布；
- `Ctrl/Cmd + 滚轮`、触控板捏合缩放；
- 右下角提供缩小、放大、适应画布和缩略图；
- “定位”按钮定位当前节点，无选中时适应全部节点；
- 每棵技能树独立保存位置、缩放和折叠状态；
- 首次打开自动适应全部节点。

### 5.2 节点操作

- 单击只选中节点并显示浮动工具栏和右侧 `+`；
- 双击就地编辑名称；
- `+` 只创建一个下一层子节点，选中仍停留在父节点，便于连续创建并行子节点；
- 工具栏“详情”打开右侧详情抽屉；
- 节点始终可拖动，不提供锁定位置功能；
- 拖到空白处保存手动位置；
- 拖到另一节点时显示虚线落点，松手后带着整棵子树重新挂载；
- 新增、删除或重挂载后只重排附近区域，优先保留其他手动位置；
- “重新自动布局”清除当前树的手动位置覆盖。

### 5.3 键盘

- `Tab`：新建子节点；
- `Enter`：新建同级节点；
- `Shift + Tab`：插入父节点；
- `Delete/Backspace`：软删除所选节点及其主子树；
- `Ctrl/Cmd + Z`：撤销；
- `Ctrl/Cmd + C/V`：复制并粘贴节点内容；
- 文字编辑时快捷键服从输入框，不触发画布命令。

### 5.4 折叠与删除

- 有子节点的卡片显示折叠按钮；
- 折叠后显示隐藏的直属子节点数量；
- 删除不弹确认框，立即软删除并显示“已删除该分支｜撤销”；
- 软删除保留成果、任务和关系数据，允许撤销或后续回收站恢复。

## 6. 详情与成果

单击节点不自动打开详情。详情抽屉沿用现有内容：节点说明、掌握标准、关联任务、状态与用户填写的成果。成果初版保持轻量，不做自动指标采集和复杂证明体系。

## 7. 自动布局

- 主父级是几何层级的唯一事实源；
- 根节点在最左侧，深度决定横向列；
- 同父级节点纵向分布并保持稳定顺序；
- 并行容器根据成员包围盒生成；
- 汇合节点位于所有成员右侧，并使用共享汇合线；
- 手动坐标覆盖自动坐标，但不改变逻辑关系；
- 只有发生重叠或结构变化的邻近分支参与增量整理。

## 8. AI 后续接口

初版只保留 `AbilityPlanner` 接口、草稿数据结构和依赖边界，不在能力模块内放置 API 配置。后续 AI 版本从主设置读取用户接入的模型 API，后台 Skill 约束输出结构、学习步骤和验收标准；AI 只生成可预览、可编辑的草稿，用户确认后才写入正式技能树。

## 9. 验收标准

- 技能树明确从左向右生长，串行、并行和汇合在布局上可辨识；
- 主线无明显交叉，辅助线弱化且能随选择高亮；
- 支持平移、缩放、缩略图、适应视图和定位；
- 节点可自由拖动，位置和视角按树保存；
- 同一父节点连续点击 `+` 可创建多个并行子节点；
- 支持拖拽重挂载、辅助连线、多选汇合、折叠、软删除和撤销；
- 不存在锁定功能或锁定状态；
- 用户的任务、成果和掌握记录不会因软删除丢失；
- 初版没有 AI 入口，但保留稳定接口。
