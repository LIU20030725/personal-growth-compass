# Dice Life 能力模块 V4：直接操作式技能树

日期：2026-08-14

## 1. 背景与问题

本次设计以飞书项目文档“0811-0816 精细化更新各模块 / V02 / 能力模块”为需求来源，并结合当前 V3 实现核对。V3 已具备阶段、节点、并行关系、资源、成果、画布与线性路线，但仍存在以下体验断点：

1. 阶段是彼此分散的背景列，没有顺序连线，也不能拖动；
2. 新增入口依赖“编辑技能树”模式，切页或状态切换后会消失；
3. 页面级“记录成果”要求用户再次选择节点，容易产生保存后不可见的错觉；
4. 画布快捷键不完整，删除后的撤销、重做和节点导航不足；
5. 节点单击不直接打开详情，画布空白也没有形成明确的关闭动作；
6. “下一步”只改变筛选，没有定位、详情、数量或空态反馈；
7. “编辑技能树”和“编辑技能树资料”语义冲突，首次创建步骤过多；
8. 阶段、节点、连线和顶部操作存在对齐与层级问题。

## 2. 产品原则

- **直接操作**：结构入口常驻在它所影响的对象附近，不要求先切换模式。
- **对象归属**：阶段操作属于阶段，成果与资源属于节点，资料修改属于技能树。
- **一种关系一种语义**：阶段线只表达阶段顺序；节点线只表达技能前置和解锁。
- **可恢复**：新增、删除、拖动、重连均进入历史；撤销和重做都可用。
- **作用域安全**：快捷键只在画布聚焦且选中节点时生效，绝不劫持原生 Tab。

## 3. 信息架构与页面操作

技能树顶部只保留：

1. `修改技能树资料`：直接打开名称、描述、角色等资料弹窗；
2. `＋ 添加阶段`：创建下一阶段；
3. `更多`：重新自动布局、快捷键说明等低频操作。

移除页面级 `记录成果` 和 `编辑技能树`。成果只能从已选节点的详情栏创建，创建表单默认且固定关联当前节点，不再显示节点下拉框。

## 4. 阶段容器与关系

- 阶段继续作为包含技能节点的容器，不变成普通技能节点；
- 阶段按 `order` 派生顺序关系线：当前阶段右侧中心至下一阶段左侧中心；
- 阶段线使用低饱和实线和方向标记，与节点主依赖线保持视觉区分；
- 阶段容器可水平/垂直拖动并按 16px 网格吸附，位置写入画布偏好；
- 拖动阶段时，阶段内技能节点随容器整体位移；不改变阶段顺序与解锁逻辑；
- `重新自动布局` 清除阶段和节点手动位置，恢复完全对齐；
- 空阶段仍可见，容器内常驻 `＋ 添加第一个技能`。

阶段位置属于视图偏好，不进入 Ability Schema，因此 V2 数据无需迁移。旧偏好数据缺少阶段坐标时使用自动布局结果。

## 5. 节点直接操作

- 节点右侧 `＋` 常驻；同一节点连续点击三次创建三个并行直接子节点；
- 拖动节点、拖动重挂载、连接辅助依赖始终可用；
- 删除与重连属于危险结构操作，只在节点选中后的浮动菜单中出现；
- 删除后显示就地提示和撤销入口；
- 单击节点立即选中并打开右侧详情；
- 单击画布空白清除选择并关闭详情；
- 双击节点或 F2 进入名称编辑。

## 6. “下一步”行动

`下一步` 不再是显示筛选，而是技能树级行动按钮：

- 候选集合为未归档、未掌握、前置条件均已掌握的节点；
- 优先顺序：学习中优先，其次阶段 order，其次创建时间与 id；
- 点击后选中第一个候选、画布居中并打开详情；
- 有多个并行候选时，重复点击按稳定顺序轮换；
- 按钮显示候选数量，例如 `下一步 · 3`；
- 无候选时不静默：区分空树、全部掌握、前置阻塞三种提示；
- “全部 / 已掌握”继续保留为显示筛选；切换视图后仍保持当前选中节点。

## 7. 快捷键

仅当画布容器拥有焦点、且恰好选中一个技能节点时启用：

| 快捷键 | 行为 |
| --- | --- |
| Enter / F2 | 编辑节点名称 |
| Ctrl/Cmd + Enter | 添加子节点 |
| Ctrl/Cmd + Shift + Enter | 添加同级节点 |
| Delete / Backspace | 删除所选分支 |
| Ctrl/Cmd + Z | 撤销 |
| Ctrl/Cmd + Shift + Z / Ctrl/Cmd + Y | 重做 |
| Ctrl/Cmd + C / V | 复制、粘贴为子节点 |
| ← / → | 选择父节点 / 第一个子节点 |
| ↑ / ↓ | 选择上一个 / 下一个同级节点 |
| Home / End | 选择同级首个 / 末个节点 |
| Escape | 清除选择并关闭详情 |
| ? | 打开快捷键说明 |

输入框、文本域、选择框、按钮、链接、菜单和对话框内均不触发画布快捷键。Tab 与 Shift+Tab 始终保留浏览器原生焦点导航。

## 8. 历史与持久化

- 领域数据历史新增 undo/redo 双栈；新修改会清空 redo 栈；
- undo/redo 均先写入持久化，失败时不移动历史指针；
- 阶段/节点拖动属于画布偏好历史，至少支持本次会话内撤销与重做；
- 画布偏好扩展为节点位置与阶段位置两个字段，旧数据读取幂等且安全降级；
- 所有坐标保存前校验有限值并吸附到 16px 网格。

## 9. 可访问性与响应式

- 画布继续使用 `application/group` 语义及同步线性路线；
- 所有图标按钮有可访问名称；快捷键面板可用 Esc 关闭并恢复焦点；
- 390px 默认线性路线；结构创建仍可从阶段和节点上下文进入，但复杂拖动不强塞进移动端；
- 详情在窄屏采用底部面板，关闭后焦点回到原节点。

## 10. 验收重点

1. 无需模式切换即可添加阶段、空阶段首节点和多个并行子节点；
2. 切树、切视图、关闭再打开后创建入口仍存在；
3. 阶段有顺序线且可拖动，重载位置保持，重置后恢复对齐；
4. 单击节点开详情、点空白关详情；
5. 成果只能从节点详情添加且自动关联当前节点；
6. 下一步可定位、轮换、显示数量和三类空态；
7. 删除后 Ctrl/Cmd+Z 恢复，重做再次删除；
8. Tab 不被拦截，表单与弹窗内快捷键不触发树操作。

## 11. 已知边界

- 阶段线不参与技能解锁；阶段依旧按显式 order 串行排列；
- 本版不加入任意阶段分叉、阶段依赖编辑器或跨树阶段连接；
- 本版不复刻飞书与技能树无关的图形、便签、评论、协作光标和格式快捷键；
- 移动端提供线性路线和详情，不提供完整画布拖动编辑体验。
