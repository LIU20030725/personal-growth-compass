# Dice Life 能力模块精细化更新 V3 设计规格

- 日期：2026-08-12
- 状态：待用户复核
- 适用模块：能力属性 / 技能树
- 承接版本：能力画布 V2.1
- 需求来源：飞书《0811-精细化更新各模块》能力模块、竞品调研及后续节点资源库确认

## 1. 产品定位

能力模块不是单纯的技能树绘图工具，而是一套以阶段为骨架、以技能节点为路径、以掌握标准和真实成果为成长证明的个人能力管理系统。

用户打开任意技能树后，应当立即得到三个答案：

1. 我现在处于哪个成长阶段；
2. 我下一步应该学习什么；
3. 我凭什么认为自己已经掌握这项技能。

核心闭环为：创建技能树 → 规划成长阶段 → 添加串行或并行技能 → 开始当前节点 → 完成掌握标准或记录成果 → 确认掌握 → 解锁下一节点或阶段。

## 2. 本次目标

1. 让“阶段”真正影响画布、进度、解锁和时间预期，解决新增阶段没有可见效果的问题。
2. 删除重复入口，把阶段、节点和并行关系的创建收进画布交互。
3. 缩短高频操作路径，使用户主要围绕“下一步、掌握标准、学习资源、真实成果”行动。
4. 修复筛选残留、连线偏移和线性视图空白等现有体验问题。
5. 增加隐藏在节点详情中的轻量学习资源库，首版由用户手动收藏链接。
6. 保持 AI 为后续可选扩展，首版不提供 AI 搜索、生成或推荐入口。

## 3. 非目标

本版本不增加排行榜、社交竞争、金币装备、成果审核、复杂统计仪表盘、公开资源社区、文件上传、网页全文剪藏、内置播放器、阅读进度、资源评分或独立知识库首页。

任务模块继续负责“今天具体做什么”；能力模块不再提供任务关联功能。

## 4. 统一术语

- 技能树：围绕一项主技能、副技能或探索技能建立的完整成长结构。
- 阶段：入门、进阶、熟练等具有目标、建议用时和完成条件的横向成长区间。
- 技能节点：阶段中的具体可学习能力。
- 前置节点：建议先掌握的技能节点。
- 掌握标准：用户定义“做到什么才算掌握”的可勾选条件。
- 学习资源：帮助学习节点的文章、视频、文档、课程、工具或其他链接。
- 真实成果：用户实际完成的项目、作品、收入、数据增长或其他成效记录。

节点状态统一为：可开始、学习中、已掌握。前置未完成只显示非阻塞提示，不引入锁定状态；用户仍可主动开始任意节点。

## 5. 页面信息架构

页面从上到下分为四层：

1. 模块标题与“新建技能树”；
2. 画布上方的紧凑技能库；
3. 当前技能树摘要与少量主操作；
4. 筛选、视图切换、画布或线性路线，以及按需打开的节点详情。

### 5.1 删除重点技能横条

删除现有“重点技能｜学习 AI｜机器人结构设计｜自媒体”横条。它与技能库和技能树切换功能重复。

### 5.2 完整技能库移到画布上方

完整技能库改为紧凑横向区域，不沿用当前的大型卡片墙：

- 默认展示最近使用或置顶的 5 至 6 棵技能树；
- 每张紧凑卡只展示名称、当前阶段和进度；
- 支持横向滚动、搜索和“查看全部”；
- 选择卡片立即切换下方技能树；
- 置顶、排序、归档等管理操作进入卡片的 `···` 菜单；
- 技能树数量仍不设上限。

### 5.3 当前技能树摘要

摘要区展示名称、角色、当前阶段、掌握比例、最近成果和进入下一阶段还差多少个必修节点。

外露主操作只保留：

- 记录成果；
- 编辑技能树；
- `···` 更多菜单。

更多菜单容纳编辑技能树资料、重新自动布局、导出和归档。添加阶段、添加节点、设置并行组和专注当前阶段不再作为页面级按钮。

## 6. 阶段系统

### 6.1 阶段是画布中的真实列

技能树保持从左向右生长。每个阶段对应一列或一个明确的纵向区域，阶段头部展示：

- 阶段序号和名称；
- 阶段目标；
- 建议用时；
- 已掌握节点数 / 必修节点数；
- 进入条件和完成条件的简要状态。

阶段字段包括：名称、目标、说明、建议用时、可选计划开始/结束日期、显示顺序和必修节点集合。计划日期为可选项，首版不建设甘特图。

### 6.2 在画布中添加阶段

最后一个阶段右侧常驻“＋ 添加下一阶段”。阶段之间在编辑状态下可显示插入按钮。

点击后在画布内打开小型浮层，只要求填写阶段名称、阶段目标和可选建议用时。保存后阶段区域立即出现，不使用大型弹窗。

空阶段必须显示阶段头部、空状态和“＋ 添加本阶段第一个技能”，并在刷新后保持。由此保证新增阶段永远有可感知反馈。

### 6.3 阶段推进规则

- 第一阶段默认可开始；
- 默认以本阶段全部必修节点已掌握作为阶段完成条件；
- 选修节点不阻塞阶段完成；
- 下一阶段未满足条件时显示“还差哪些必修节点”，但不禁止用户查看或提前开始；
- 用户可在编辑阶段时调整节点是否必修；
- 删除非空阶段前必须先选择移动节点到其他阶段或一并归档。

## 7. 画布操作模式

### 7.1 浏览 / 成长状态

默认进入浏览状态。用户可以移动、缩放、选择节点、查看详情、开始学习、勾选标准、记录成果和确认掌握。删除、重挂载、拖动节点和新增控件不常显。

### 7.2 编辑状态

点击“编辑技能树”后进入编辑状态，显示：

- 节点右侧加号；
- 节点拖动和重挂载；
- 阶段新增、插入与编辑；
- 节点删除和名称编辑；
- 撤销、重新自动布局等编辑工具。

退出编辑状态后保留视口和节点选择，但隐藏所有编辑控件。

### 7.3 串行与并行创建

- 点击某节点的 `+` 创建一个下一层子节点；
- 连续点击同一父节点的 `+`，创建多个同级子节点，系统自动视为并行；
- 点击某个子节点的 `+`，继续其串行分支；
- 不再提供“设置并行组”表单或页面级按钮；
- 并行外框和共享母线由同父、同层关系自动推导；
- 多选并创建共同下一步属于高级编辑操作，仅在编辑状态的上下文工具中出现。

### 7.4 画布工具收敛

右下角保留放大、缩小和适应视图。撤销在编辑状态可发现。定位、重新自动布局等低频功能进入紧凑工具条或更多菜单。快捷键提示不再占据整条画布顶部，改为帮助提示。

## 8. 节点详情

节点详情只在用户点击节点后打开。没有选中节点时不显示详情内容。

详情顺序为：节点头部与说明 → 掌握标准 → 学习资源 → 真实成果。

### 8.1 删除重复区域

- 删除“掌握判断依据”文本框；
- 删除“关联任务”整个区域；
- 编辑、归档和退回状态等低频操作统一放入 `···` 菜单。

### 8.2 掌握规则

用户满足下列任一条件后可以确认掌握：

1. 已定义至少一条掌握标准，且所有标准均已满足；
2. 当前节点已记录至少一项真实成果。

两者均不满足时禁用“确认已掌握”，并提示“请先添加掌握标准或记录一项成果”。学习资源不计入掌握证据，打开链接也不自动改变进度。

节点根据状态只展示一个主操作：可开始显示“开始学习”，学习中显示“确认已掌握”，已掌握显示“查看成果”或状态摘要。

## 9. 节点学习资源库

### 9.1 产品原则

学习资源是隐藏在节点内部的轻量知识储存能力。资源不会出现在画布节点、连线、阶段外框或线性路线卡片上，也不在画布显示资源数量。

首版仅由用户手动收藏。AI 搜索和推荐留作后续版本。

### 9.2 展示规则

- 没有选中节点时不显示资源区；
- 选中节点后，在掌握标准与真实成果之间显示“学习资源”；
- 无资源时只显示数量 0 和“＋ 收藏资源”；
- 有资源时默认展示前 3 项，超过 3 项提供“查看全部”；
- 支持手动折叠；
- 切换节点后只展示新节点的关联资源；
- 移动端在节点详情底部抽屉内显示。

单条资源以标题为主，辅助显示类型和来源域名。点击标题在外部新窗口打开。`···` 菜单提供编辑标题或备注、关联到其他节点、从当前节点移除和删除资源。

### 9.3 收藏流程

点击“＋ 收藏资源”后使用紧凑内联表单或浮层，不使用大型弹窗。字段为：

- 链接：必填，仅接受 HTTP / HTTPS；
- 标题：必填，可在技术允许时读取网页标题自动填充；
- 类型：视频、文章、文档、课程、工具、其他；
- 来源：自动提取域名；
- 学习备注：选填；
- 收藏时间：自动记录。

入口分为“粘贴新链接”和“从资源库选择”。从资源库选择时提供标题、域名和备注搜索，不增加文件夹和多层标签。

### 9.4 统一资源与节点关联

资源作为全局唯一对象保存，节点只保存关联关系：

- 同一资源可以关联多个技能节点；
- 对规范化 URL 去重；
- 从当前节点移除只解除关联，不删除资源；
- 资源没有任何节点关联时，用户才可以彻底删除；
- 删除或归档节点不删除资源原件；
- 同一链接再次收藏时提示已存在，并允许直接关联到当前节点。

URL 规范化只处理主机名大小写、明显的尾部斜杠和常见追踪参数，不移除可能决定页面内容的业务查询参数。

### 9.5 首版资源限制

首版不支持文件上传、网页全文保存、内置阅读器、视频播放、阅读时长、完成率、标签层级、评分、公开分享或独立知识库首页。

## 10. 筛选与切换状态

现有筛选收敛为：全部、下一步、已掌握。

“下一步”包含学习中、当前可开始和当前阶段即将推进的节点，不再同时暴露“当前阶段、成长中、可开始”等重叠入口。

每次筛选或切换技能树时必须统一重新计算：可见节点、连线、阶段、并行外框、成果、当前选择和视口。

被隐藏节点不得继续保持选中，详情不得显示已隐藏节点；无可见成员的并行外框和阶段装饰不得残留；成果只在其关联节点可见且用户明确选择树上展示时出现。切换技能树后默认回到“全部”。

## 11. 画布几何与视觉

### 11.1 连线

- 同一水平中心的单条串行边必须为完全水平直线；
- 不允许出现几像素的先水平、再上下偏移、再水平；
- 一对多关系继续使用共享分支母线；
- 来源和目标 handle 位于节点左右两侧的垂直中心；
- SVG 路径终点 Y 必须等于目标 handle 中心 Y；
- 箭头与节点边框保持统一间距；
- 主依赖使用实线，辅助依赖使用虚线；
- 阶段外框、节点、标题和母线共用 16px 几何网格。

### 11.2 视觉状态

黄色只用于当前选择、主要操作和关键进度。未选节点、点阵和工具阴影继续弱化。切换筛选、视图或技能树后不得遗留上一状态的焦点、选中描边或容器效果。

## 12. 线性视图与移动端

线性视图改为按阶段分组的紧凑列表，而非大高度横向卡片区：

- 阶段头部显示目标和进度；
- 节点按依赖顺序纵向排列，可在宽屏使用紧凑双列；
- 节点显示序号、名称、状态、前置提示和成果数量；
- 左侧内容高度由实际内容决定，不继承画布最小高度；
- 列表与右侧详情从同一顶部基线开始；
- 右侧详情移除掌握判断依据和关联任务，并加入学习资源；
- 390px 及更窄视口默认使用线性路线，节点详情使用抽屉或底部面板；
- 移动端支持浏览、开始学习、勾选标准、收藏资源、记录成果和确认掌握，复杂结构编辑仍建议使用桌面端。

## 13. 数据边界

现有能力状态需要增加以下概念：

- 阶段目标、建议用时、可选日期和阶段完成设置；
- 节点是否为阶段必修；
- 全局学习资源；
- 节点与资源的多对多关联。

节点中的 `masteryNote` 和能力模块中的任务关联不再参与新界面及新业务规则。迁移时保留旧数据以避免用户内容丢失，但新版本停止创建相关数据；后续稳定版本再决定是否物理移除。

资源应至少包含：ID、URL、规范化 URL、标题、类型、来源域名、备注、来源类型、创建时间和更新时间。首版来源类型固定为 manual；为后续 AI 推荐预留 ai、推荐理由、适用节点、难度和置信度，但不在首版 UI 展示。

## 14. 错误与边界处理

- 非 HTTP / HTTPS 链接不允许保存，并显示可理解提示；
- 无法读取网页标题时允许用户手动填写并继续保存；
- 重复链接提示已存在，不创建重复资源；
- 外部链接失效不自动删除资源；
- 阶段保存失败时保留用户输入并显示重试入口；
- 删除非空阶段、彻底删除未关联资源等不可逆操作需要明确确认；
- 节点、筛选或技能树切换期间不得显示上一对象的详情数据。

## 15. 可访问性

- 浏览状态和编辑状态的名称、当前状态及切换结果应可被读屏识别；
- 资源列表使用语义化列表，资源标题为可聚焦链接；
- 所有图标按钮提供可理解名称；
- Tab 只执行原生焦点移动，不创建节点；
- 画布快捷键仅在画布明确激活且焦点不在表单、按钮、链接或对话框时生效；
- 线性视图继续作为键盘和读屏的完整替代路线。

## 16. 验收标准

### 16.1 阶段与画布

1. 新增第二、第三阶段后，画布立即显示对应区域，刷新后仍保留。
2. 空阶段显示名称、目标、建议用时和添加第一个技能的入口。
3. 同一父节点连续点击三次 `+` 产生三个并行子节点。
4. 点击某子节点 `+` 正确创建后续串行节点。
5. 阶段进度、必修节点和下一阶段提示计算一致。

### 16.2 精简与详情

1. 重点技能横条、设置并行组、专注当前阶段、掌握判断依据和关联任务不再出现。
2. 页面级主操作只保留记录成果、编辑技能树和更多菜单。
3. 未达到标准且没有成果时不能确认掌握。
4. 达成全部掌握标准或存在真实成果时可以确认掌握。

### 16.3 学习资源

1. 未选择节点时不显示资源库。
2. 资源不出现在画布和线性路线节点上。
3. 用户可以手动收藏、打开、编辑、关联和移除链接。
4. 同一链接只保存一份，并可关联多个节点。
5. 从节点移除不会误删资源原件；删除节点也不删除资源原件。
6. 超过三项资源只默认展示三项。
7. 打开或收藏资源不会自动改变节点进度。

### 16.4 筛选、几何和响应式

1. 切换筛选后无空并行框、残留成果、错误详情或旧选中状态。
2. 同高度串行边完全水平，终点与目标 handle 中心一致。
3. 3 分支、5 分支和多层分支仍共享正确母线。
4. 线性视图从顶部紧凑排列，列表与详情顶部对齐，无大面积空白。
5. 390×844 下可完成全部成长、资源和成果操作。
6. 单元测试、构建、E2E 和可访问性测试通过，axe critical / serious 为 0。

## 17. 建议实施顺序

### P0：修复现有错误

1. 修复阶段新增无可见效果及持久化问题；
2. 修复串行线偏移；
3. 修复筛选后的节点、成果、外框和详情残留；
4. 修复线性视图高度和顶部对齐。

### P1：精简信息架构与画布创建

1. 技能库移到画布上方并紧凑化；
2. 删除重复入口和详情区域；
3. 增加浏览 / 编辑状态；
4. 阶段、节点和并行创建进入画布；
5. 筛选收敛为全部、下一步和已掌握。

### P2：节点学习资源库

1. 增加全局资源及节点关联数据；
2. 增加节点内收藏、查看和复用流程；
3. 完成 URL 去重、删除语义和移动端交互；
4. 预留 AI 推荐字段但不增加 AI 界面。

### P3：阶段价值强化

1. 阶段目标、建议用时、必修节点和完成条件；
2. 下一步提示及进入下一阶段差距；
3. 当前阶段和最近成果摘要。

## 18. 后续版本

后续可在不改变首版手动优先原则的前提下增加：AI 生成技能树草稿、AI 推荐节点资源、资源失效检测、独立资源管理入口、模板导入和只读分享。所有 AI 结果都必须先由用户预览并确认，不得自动写入正式技能树或资源库。
