# 冒险日志模块 Spec 文档区

**所属分支：** `codex/adventure-journal/main`

本目录只存放 冒险日志 模块自己的产品、视觉和实施文档。跨模块共用规则应写入主分支公共文档，再由本模块引用。

## 文件说明

1. [01-模块方案-PRD.md](./01-模块方案-PRD.md)：记录目标、范围、功能规则、数据关系和验收标准。
2. [02-UI美术设计风格.md](./02-UI美术设计风格.md)：记录该模块在项目总体美术风格下的专属 UI 规范。
3. [03-计划实施路线.md](./03-计划实施路线.md)：记录开发阶段、任务拆分、测试和合并路线。

## 使用顺序

```text
方案讨论
  → PRD 确认
  → UI 美术风格确认
  → 实施路线确认
  → 模块分支开发
  → 测试与构建
  → 合并回 main
```

## 维护规则

- 每份文档顶部写明版本、日期和状态。
- 只记录本模块内容，避免把其他模块的实现混入当前分支。
- 发生跨模块依赖时，在 PRD 中明确依赖模块、输入、输出和负责人。
- 正式开发前先确认 PRD 与实施路线。
- 合并回 `main` 前更新文档状态和变更记录。
