# 冒险日志模块规格与版本中心

**所属分支：** `codex/adventure-journal/main`

本目录是冒险日志模块的产品、视觉、架构、实施与版本记录中心。跨模块共用规则继续由主分支公共文档维护，本模块只引用，不复制多份源码或公共规范。

## 文件说明

1. [01-冒险日志-PRD.md](./01-冒险日志-PRD.md)：目标、范围、玩法规则、数据关系和验收标准。
2. [02-UI美术设计.md](./02-UI美术设计.md)：模块在 Dice Life 总体风格下的专属视觉规范。
3. [03-计划实施路线.md](./03-计划实施路线.md)：V0.1.0 到 V1.0.0 的开发、测试和合并路线。
4. [04-模块架构与版本设计.md](./04-模块架构与版本设计.md)：代码边界、数据流、页面结构、异常恢复和发布设计。
5. [VERSION.md](./VERSION.md)：当前模块、数据和内容版本。
6. [CHANGELOG.md](./CHANGELOG.md)：按模块语义版本维护的变更记录。
7. [`releases/`](./releases/)：各版本冻结后的范围、验收证据和迁移说明；不存放源码副本。

## 使用顺序

```text
方案讨论
  → PRD 确认
  → UI 美术风格确认
  → 实施路线确认
  → 架构与版本设计确认
  → 详细实施计划
  → 模块分支开发
  → 测试与构建
  → 合并回 main
```

## 维护规则

- 每份文档顶部写明版本、日期和状态。
- 只记录本模块内容，避免把其他模块的实现混入当前分支。
- 发生跨模块依赖时，在 PRD 中明确依赖模块、输入、输出和负责人。
- 正式开发前先确认 PRD 与实施路线。
- 合并回 `main` 前更新文档状态和变更记录。
- 当前代码只维护在 `src/adventure-journal/`；历史代码由 Git 提交和模块标签保存。
- 发布目录只记录版本快照、迁移和验收证据，不复制整套源代码。
