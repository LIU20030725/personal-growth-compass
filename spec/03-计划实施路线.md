## 1. 实施目标

以可运行的纵向切片建立冒险日志的稳定边界，再沿同一份源码逐步补齐完整 V1。最终交付必须覆盖旅途、永久家园、固定价格投资、地图与物件解锁、旅途发现、旅行用品、阶段回顾、成长信箱、声音与低动态模式。

不采用复制整套源码的版本目录。源码持续位于 `src/adventure-journal/`，版本历史由 Git、模块标签、迁移脚本和 `spec/releases/` 共同保存。

## 3. 版本路线

### V0.1.0：可运行纵向切片

- 旅途 / 家园双页面和现有 Dice Life 外壳接入。
- 首张地图和通往第二张地图的路线投资。
- 两个可部分投入的家园物件。
- 任务骰子账本读取与 `adventure-spend` 支出。
- 操作 ID 去重、待处理操作恢复和本地持久化。
- 原创明亮像素场景基线、静态资源降级和低动态模式。
- 业务、存储、组件和 App 集成测试。

### V0.2.0：内容与收藏扩展

- 三张单线地图和旧地图自由切换。
- 每张地图 25% / 50% / 75% 固定发现。
- 六至八个家园物件、固定插槽与图纸来源。
- 三至五件纯外观旅行用品。
- 内容清单独立版本化和按需资源加载。

### V0.3.0：回顾与氛围闭环

- 主动启程、阶段草稿和阶段归档。
- 成长信箱、当前草稿和阶段来信。
- 任务历史的财富、能力、健康三维汇总。
- 环境音乐、环境音、界面音和用户偏好记忆。
- 天气、昼夜与页面不可见时暂停非必要动画。

### V1.0.0：完整发布

- 全部 PRD 与视觉验收项逐条通过。
- 数据迁移、损坏备份、恢复和性能预算收敛。
- 宽屏、中等桌面和窄桌面视觉验收。
- 完整测试、生产构建、变更记录和发布证据冻结。

| 层级 | 必须覆盖 |

| 领域单元测试 | 固定价格、余额、部分投入、进度上限、阈值发现、单次解锁、主动启程 |
| 存储测试 | 往返保存、迁移、损坏备份、待处理操作恢复、重复操作去重 |
| 组件测试 | 双页面切换、投资对话框、地图切换、信箱状态、键盘操作 |
| 集成测试 | 任务奖励到账、冒险支出一次、任务归档后交易保留、旧地图不改变阶段 |
| 视觉测试 | 1440px、1180px、窄桌面、低动态、资源降级 |
| 完整回归 | `npm test`、`npm run build`、`git diff --check` |

## 6. 跨模块依赖

| 依赖模块 | 输入 | 输出 | 边界 |
| --- | --- | --- | --- |
| 任务模块 | 骰子交易、任务完成历史、目标历史 | 冒险支出交易引用 | 任务模块继续拥有骰子收入账本 |
| App 外壳 | Header、Sidebar、主导航、页面切换 | 冒险日志页面入口 | 不重做全局布局 |
| 全局风格 | 字体、颜色、硬边框、硬阴影 | 模块级场景 Token | 像素风只进入冒险舞台 |

## 7. 风险与回退

- 双存储写入中断：使用待处理操作日志和启动恢复，不依赖不可用的跨键原子事务。
- 场景资源过重：首屏只加载当前地图，旧地图、家园和音频按需加载。
- 像素风破坏系统一致性：页面外壳与功能浮层始终遵循 `STYLE.md`。
- 本地数据迁移失败：保留带时间戳的原始备份，不覆盖损坏数据。
- 视觉资源缺失：使用静态占位并保持所有数值操作可用。
