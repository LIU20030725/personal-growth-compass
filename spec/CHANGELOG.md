# 冒险日志模块变更记录

本文件遵循 Keep a Changelog 的结构，版本号遵循语义版本。日期使用 `YYYY-MM-DD`。

## [Unreleased]

暂无待发布变更。

## [0.1.0] - 2026-08-01

### Added

- 建立独立的 `src/adventure-journal/` feature package、schema 1 存储与内容版本 0.1.0。
- 实现旅途与永久之家双页面、晴日林径原创像素场景和两个家园物件。
- 实现通往风过山谷 30 骰子、田野书桌 6 骰子、记忆陈列架 12 骰子的固定价格部分投入。
- 接入任务模块骰子账本，写入带操作与目标引用的 `adventure-spend` 交易。
- 实现操作 ID 去重、待处理操作恢复、损坏数据备份与旧任务冒险字段迁移。
- 增加投入对话框、骰子账本、余额不足提示、低动态模式与响应式布局。
- 接入 Dice Life 顶部导航的“冒险日志”入口。
- 建立 V0.1.0 至 V1.0.0 的版本路线、发布快照和视觉证据目录。

### Changed

- 将分支 PRD 和 UI 文档改为明确的冒险日志文件名。
- 补全架构、实施路线、详细测试驱动计划和版本管理规则。
- 扩展任务账本以支持幂等的冒险支出目标元数据。

### Fixed

- 修复浏览器原生数字约束阻止页面内投入错误提示的问题。
- 保证账本写入后意外中断时只恢复进度，不重复扣除骰子。
- 补齐标签页与内容区的无障碍关联、原生禁用状态和进度语义。

## 发布格式

每次正式发布把 `[Unreleased]` 中已交付内容移动到：

```text
## [0.2.0] - 2026-XX-XX
```

并同步更新 `VERSION.md`、运行时模块版本、迁移说明、验收证据和 Git 标签。
