## 本次发布

### 今日总览与身体健康 revision 2083

- 今日总览聚焦今日状态、一键记录、最近身体变化和健康工作台入口。
- 训练采用顶部计时器、三阶段动作计划和可搜索/筛选的动作库。
- 饮食提供剩余热量、三大营养素、能量台账、四餐入口和三类食物库。
- 日常健康覆盖饮水目标与提醒、久坐提醒、活动和睡眠记录。
- 身体状态覆盖七类围度、体重、体脂、BMI、胸腰比和腰臀比。
- 详细资料：[`docs/健康模块/UI优化-v03/`](../../../docs/健康模块/UI优化-v03/)

### 能力 V5.1

- 首屏信息层级收敛，当前技能与下一步成为明确的标题和主动作。
- 真实数据首屏直接显示技能图；常用工具和低频工具分层。
- 保留连接点按需显现、阶段扩缩、拖拽、撤销/重做、资源、成果和移动路线。
- 详细资料：[`src/ability/docs/`](../../../src/ability/docs/)

### 情绪 v1.5

- “记录此刻”桌面端一步进入编辑器，日记、内容库和心情日历回到页面内容流。
- 情绪与活动按类别渐进展开，减少首屏选择噪声。
- 保留文字、图片、视频、语音、音乐、重要日、收藏和本地优先持久化。
- 详细资料：[`docs/情绪模块/验收证据/2026-08-15-v1.5/`](../../../docs/情绪模块/验收证据/2026-08-15-v1.5/)
