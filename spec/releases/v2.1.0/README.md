## 本次发布

### 情绪

- 支持网易云音乐、QQ 音乐元数据识别与安全降级。
- 完成服务端信任边界、响应限制、限流和前端竞态加固。
- 详细资料：[`docs/情绪模块/`](../../../docs/情绪模块/)

### 能力

- 阶段容器直接拖动，阶段顺序与节点依赖分离表达。
- 节点详情、成果绑定、下一步候选轮换、画布撤销/重做和快捷键完整落地。
- 详细资料：[`src/ability/docs/`](../../../src/ability/docs/)

### 身体健康

- 身体指标、训练、饮食、睡眠和饮水形成完整本地记录闭环。
- 支持历史更正、回收站、导出、完整预检与整体恢复。
- 详细资料：[`docs/健康模块/`](../../../docs/健康模块/)
