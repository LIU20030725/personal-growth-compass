# 冒险日志 V0.1.0 发布规格

**状态：** 已发布（2026-08-01）
**模块版本：** `0.1.0`
**schema：** `1`
**内容版本：** `0.1.0`
**实施分支：** `codex/adventure-journal/main`
**稳定标签：** `adventure-journal-v0.1.0`

**详细实施计划：** [`IMPLEMENTATION_PLAN.md`](./IMPLEMENTATION_PLAN.md)

## 交付范围

- 旅途 / 家园双页面。
- 首张地图和通往第二张地图的固定价格路线。
- 两个可部分投入的家园物件。
- 任务骰子余额读取和冒险支出交易。
- 操作 ID 去重、待处理操作恢复和本地持久化。
- 原创明亮像素场景基线、静态资源降级和低动态模式。
- 领域、存储、组件和 App 集成测试。

## 不包含

- 第三张地图和完整发现内容。
- 完整家园物件与旅行用品清单。
- 阶段来信、成长信箱内容界面和任务历史汇总。
- 环境音乐、完整天气和昼夜变化。

以上内容依次进入 V0.2.0 和 V0.3.0，最终在 V1.0.0 完整验收。

## 迁移规则

V0.1.0 是冒险日志独立存储的首个 schema。若检测到旧任务状态中的简化 `adventure` 字段，迁移器只读取可映射的章节与位置，不删除或覆盖原任务数据，并在迁移前保留原始备份。

已验证：正常数据往返保存、损坏 JSON 备份并重建、旧任务章节与位置种子迁移、待处理操作按账本事实恢复。独立存储键为 `dice-life.adventure-journal.v1`。

## 已知限制与下一版本入口

- V0.1.0 仅开放晴日林径；风过山谷在路线达到 30 骰子后进入就绪态，主动启程进入 V0.2.0。
- 旅途发现、旧地图自由切换、更多家园物件和旅行用品进入 V0.2.0。
- 阶段回顾、成长信箱、声音、天气和昼夜系统进入 V0.3.0。
- 当前数据以浏览器本地存储为准，尚未提供跨设备同步。

V0.2.0 的进入条件是保留 schema 1 兼容、保留已投资固定价格，并为新增地图与内容清单提供迁移及回归测试。
