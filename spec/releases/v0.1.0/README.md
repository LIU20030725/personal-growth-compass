# 冒险日志 V0.1.0 发布规格

**状态：** 计划中
**模块版本：** `0.1.0`
**计划 schema：** `1`
**计划内容版本：** `0.1.0`

## 交付范围

- 旅途 / 家园双页面。
- 首张地图和通往第二张地图的固定价格路线。
- 两个可部分投入的家园物件。
- 任务骰子余额读取和冒险支出交易。
- 操作 ID 去重、待处理操作恢复和本地持久化。
- 原创明亮像素场景基线、静态资源降级和低动态模式。
- 领域、存储、组件和 App 集成测试。

## 不包含

- 第三张地图和完整发现内容。
- 完整家园物件与旅行用品清单。
- 阶段来信、成长信箱内容界面和任务历史汇总。
- 环境音乐、完整天气和昼夜变化。

以上内容依次进入 V0.2.0 和 V0.3.0，最终在 V1.0.0 完整验收。

## 发布证据清单

发布时必须补充：

- 测试文件与测试数量。
- `npm test` 输出摘要。
- `npm run build` 输出摘要。
- 1440px、1180px 和窄桌面验收截图索引。
- schema 迁移和损坏恢复测试结果。
- 与任务模块联调结果。
- 已知限制与下一版本入口。

## 迁移规则

V0.1.0 是冒险日志独立存储的首个 schema。若检测到旧任务状态中的简化 `adventure` 字段，迁移器只读取可映射的章节与位置，不删除或覆盖原任务数据，并在迁移前保留原始备份。
