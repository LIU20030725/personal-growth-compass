# 冒险日志视觉整改 V1.2-0803

**内部版本：** `1.2.0-0803`

**上一版本：** `1.1.0-0802`

**日期：** 2026-08-03

**状态：** 已完成

**实现提交：** `0ad6cfd0cd13e53375dc979f1d17e31a2c458c29`

## 本轮目标

修复旅途场景的素材拼接、角色裁切和首屏信息被压低等显示问题，并把页面收敛为高级、简约、治愈的像素旅途日志。章节、场景、当前位置、路线目标、进度和主要操作在桌面、平板与手机首屏中组成一条完整叙事。

## 本次变更

- 场景由两张不可无缝衔接的滚动背景改为一张完整背景，消除竖向接缝、重复块和图层错位。
- 旅行者动画按素材真实的四帧切片播放，修复按六帧计算导致的空帧、非当前帧和角色裁切。
- 限制场景高度并重构 1440×900、1024×768、390×844 三档首屏比例，使路线目标与主要 CTA 始终可见。
- HUD 精简为“当前位置”和“路线进度”，提高字号、对比度和可读性，删除重复里程碑、版本号和英文微标签。
- 路线 Dock 改为统一网格，目标、进度和 CTA 基线对齐；390px 下自然切换为单列，CTA 保持不换行。
- 统一冷象牙白、鼠尾草绿与少量暖阳黄的视觉系统，并统一 14–18px 圆角和低透明绿色阴影。
- 动效收敛为角色行走、草木轻微反馈和状态转场，继续尊重用户的减少动态偏好。
- 统一 0、部分投入和完成三种状态的章节名、当前位置、目标地、百分比、数值进度、余额与按钮文案。
- 保留投入/账本对话框焦点圈定、Escape 关闭、焦点恢复、任务中心 CTA、标签页键盘导航和偏好持久化能力。

## 问题根因与处理

1. 原始 1024×512 场景图本身完整，但旧实现复制为 200% 宽的滚动层并位移；素材不具备无缝平铺条件，因此产生明显接缝。现改为单图完整覆盖。
2. 角色素材实际为四帧，旧实现却使用六帧背景尺寸和五步动画，导致空帧与裁切。现按四倍条带宽度和四帧几何播放。
3. 旧场景只用 `aspect-ratio: 2 / 1`，1440px 下高度过大，把路线 Dock 推到首屏底部。现为各断点设置受控高度，并保持场景主体比例。
4. 进度同时出现在 HUD、里程碑和 Dock，造成视觉噪声与状态不一致风险。现只保留 HUD 百分比和 Dock 数值进度两种互补表达。

## 已知限制

- 当前只有“晴日林径”完整场景资产；抵达“风过山谷”后复用现有场景并通过状态层表达抵达，独立山谷场景留待后续版本。
- 昼夜、天气、环境声音、旅行发现相册和下一目的地切换尚未纳入本轮。
- 本轮验证覆盖默认亮色主题；尚未设计独立深色像素场景。
- 动画为轻量 CSS 像素帧与环境反馈，暂未加入更复杂的天气粒子或多层景深系统。
