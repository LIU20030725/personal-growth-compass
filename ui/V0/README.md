# V0 UI Archive

Date: 2026-07-04

V0 is the archive of the original UI direction before the next redesign pass.
It should be treated as the baseline snapshot for comparison, not as the final visual target.

## Screenshot

![GoldQuest Finance V0](./assets/goldquest-finance-v0.png)

## Current Direction

- Light, clean, card-based dashboard.
- Finance page themed as a light RPG management panel.
- Uses gold/yellow as the main identity color, with green for positive finance states.
- Layout includes:
  - Top navigation
  - Left character/status sidebar
  - Net worth hero metric
  - Income, expense, and balance stat cards
  - Account and investment cards
  - Quest/achievement progress panel
  - Monthly progress calendar

## What To Preserve

- Clean white surface and readable card structure.
- GoldQuest Finance naming direction.
- Character-level panel on the left.
- Financial data remains clear and practical.
- Game elements are present but not overwhelming.

## What To Improve In Later Versions

- Stronger "life game system" identity beyond finance-only RPG skin.
- More distinctive game UI hierarchy: status bar, quest board, rewards, inventory, skill/attribute growth.
- More intentional iconography and badges.
- Better connection between real-life actions and game-like progress.
- More visual richness without making the page cluttered.
