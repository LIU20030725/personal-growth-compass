# 关键旅程测试场景

## TS-01 首次记录

**目标：** 首次用户理解四入口并在 30 秒内完成首条记录。  
**起始条件：** 全新本地存储；桌面或移动 Web。  
**角色：** 首次用户。  
**步骤：** 进入健康首页 → 识别四入口 → 进入日常健康 → 点击 250 ml。  
**预期：** 首页不展开四套表单；记录后今日饮水立即更新；有文字状态反馈；免责声明可见。

## TS-02 身体记录生命周期

**目标：** 验证新增、更正、趋势、删除与恢复。  
**起始条件：** 有两条不同日期身体记录。  
**角色：** 返回用户。  
**步骤：** 新增身高/体重/体脂 → 更正体重 → 查看 30 天趋势 → 删除 → 数据与隐私 → 恢复。  
**预期：** BMI 只读；更正生成修订链且旧身高快照不变；删除记录不参与趋势；恢复后数据回到历史。

## TS-03 日常指标偏好

**目标：** 验证睡眠/饮水与指标关闭。  
**起始条件：** 已有一条睡眠和饮水历史。  
**角色：** 返回用户。  
**步骤：** 保存睡眠 → 保存饮水 → 关闭饮水/睡眠 → 检查快速区 → 再启用。  
**预期：** 关闭后快速输入隐藏；历史仍保留；重新启用后原历史和当日汇总恢复显示。

## TS-04 餐食与本地照片

**目标：** 验证文字+照片记录、删除和导出。  
**起始条件：** 浏览器支持 IndexedDB；准备 JPG/WebP 测试图。  
**角色：** 普通用户。  
**步骤：** 选择餐次 → 输入文字和饱腹感 → 选择照片 → 保存 → 删除 → 导出备份。  
**预期：** 照片只写入 IndexedDB；最多三张、单张≤8 MB；无外部请求；导出 manifest 媒体数正确；永久删除需确认并清理媒体。

## TS-05 五类运动记录

**目标：** 验证五种标准模式、多组、复制与计时。  
**起始条件：** 空训练库。  
**角色：** 运动记录用户。  
**步骤：** 依次创建距离计时、重量次数、自重次数、定时组数、时长训练 → 保存 → 复制上次 → 添加多组 → 启动/暂停/延长/跳过计时 → 保存。  
**预期：** 五模式产生一致 session/entry/set 结构；复制为深拷贝；历史不随草稿变化；计时状态刷新可恢复。

## TS-06 快速补录与草稿恢复

**目标：** 验证训练中断后的数据保护。  
**起始条件：** 已有完成训练。  
**角色：** 返回用户。  
**步骤：** 复制上次训练 → 刷新 → 恢复草稿 → 放弃；另一路快速补录并完成。  
**预期：** 草稿持久化且可恢复/放弃；放弃不改历史；重复结束不生成重复完成记录。

## TS-07 备份恢复

**目标：** 验证预检、明确替换与完整往返。  
**起始条件：** 有结构记录与照片；另备损坏、重复 ID、孤儿媒体样本。  
**角色：** 数据所有者。  
**步骤：** 导出 → 清空隔离测试环境 → 粘贴备份 → 预检 → 确认替换 → 对比；分别导入异常样本。  
**预期：** manifest、记录数、媒体数、校验和一致；异常样本不改变正式数据；替换需明确确认；当前格式为单文件 JSON bundle，不宣称 ZIP。

## TS-08 人工计时门禁

**目标：** 测量常用记录效率。  
**起始条件：** 5 名目标用户、各自熟悉程度记录清楚。  
**角色：** 首次与返回用户混合。  
**步骤：** 每人完成饮水、餐食文字、身体记录和已有项目单组更新；记录完成时间。  
**预期：** 常用单条中位数≤30 秒；已有项目单组更新≤5 秒。  
**状态：** 上线前人工门禁，当前自动化与单人浏览器演练不能替代 5 人验证，也不据此宣称激活率或认知指标通过。
