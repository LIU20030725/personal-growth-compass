## 明确限制

1. 备份格式是带 manifest 与 checksum 的单文件 JSON bundle，不是 ZIP。
2. 冲突策略为“预检后由用户确认整体替换”，V1 不做逐条 updatedAt 合并；不会把覆盖合并冒充已实现。
3. 真实 5 人任务时间、激活率和认知指标尚未验证，不能宣称通过。
4. 同一 20 条训练夹具中的 5 条高级结构现均可由折叠 UI 表达；无法表达主要结构 0/20（0%），低于 kill criterion 的 20%。
5. 仍保留两项上线前人工门禁：5 名真实用户任务计时，以及中端设备真实照片容量/性能；不以自动化结果冒充。
