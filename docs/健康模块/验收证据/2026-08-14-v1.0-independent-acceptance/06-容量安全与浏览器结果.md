# 容量、安全与浏览器结果

## 容量

- 自动压力夹具：1,000 条结构记录 + 50 张受控 WebP 数据对象。
- 结果：创建 manifest、计算校验和、序列化、严格导入往返在测试环境小于 1 秒；记录数、媒体数、校验和一致；无孤儿媒体。
- 注意：受控照片为极小数据，不替代中端设备 50 张真实压缩照片的人工门禁。单文件导入上限 25 MB、媒体上限 150、单张新照片上限 8 MB。

## 安全/隐私扫描

- `src/health` 无 `fetch`、XMLHttpRequest、sendBeacon、外部 URL 或 console 调试输出。
- 无密钥、token、密码等秘密字面量。
- 健康值不进入 URL、console 或遥测。
- 照片写入 IndexedDB；导出仅由用户点击触发。
- 导入防护：25 MB 上限、危险键扫描、版本、校验和、集合内唯一 ID、训练引用、媒体格式/数量、孤儿/缺失媒体检查。

## 浏览器

- 本机 URL：`http://127.0.0.1:5173/`。
- 视口：1440×900、1024×768、390×844。
- 三档页面均无水平溢出；390px 实测 `scrollWidth === clientWidth`。
- 健康页可见按钮最小触控高度 44px。
- 实测旅程：进入健康模块、身体保存、餐食填写、日常指标页、创建卧推、多组记录、开始/暂停倒计时、刷新恢复、数据/垃圾箱。
- 新建干净标签页后重跑健康入口→身体保存→运动页，页面 console error/warn：0；浏览器控制环境自身 Statsig 网络警告不属于被测页面。
- 截图目录：`screenshots/`；首页、快速记录、身体趋势、餐食记录、日常指标、逐组训练、休息计时、数据导入导出、含记录垃圾箱共 9 个场景，每个场景均用同源固定尺寸验收画布归档 1440×900、1024×768、390×844 三档 `*-final.png`，共 27 张；像素尺寸已通过 Pillow 复核。

## 可访问性

- axe 自动扫描健康首页与各子页：critical/serious = 0。
- 保存/删除/导入结果使用 `role=status`；计时区域使用 `aria-live`。
- `prefers-reduced-motion` 禁用健康模块动画与平滑滚动。
- 趋势使用文字摘要，没有仅靠颜色的状态。
- 主要旅程可由语义 button/input/select 完成；本轮没有自定义模态框，系统 confirm/prompt 的焦点约束由浏览器提供。
