# 代码审查（基线 1de7688）

## 范围

`src/health/**`、`src/App.tsx` 的健康入口，以及基线提交中的测试。按 correctness、security/privacy、performance、maintainability 审查。

## Critical

### C-01 导入包缺少完整性与引用校验

- 位置：`healthStorage.ts`、`useHealthSystem.ts#importBundle`
- 问题：仅检查顶层数组存在；不校验重复 ID、媒体引用、版本、校验和、数据 URL 大小/格式。媒体直接写入正式 IndexedDB 后才提交结构数据，已有同 ID 媒体可能被覆盖，失败回滚会删除原媒体。
- 影响：损坏或构造的备份可能污染正式数据、破坏原照片，无法满足“导入失败不改变正式数据”。
- 决定：必须修复。增加清单、校验和、严格预检、大小/数量上限、ID/引用检查和媒体暂存/回滚策略；UI 先预检再明确替换。

### C-02 React 状态闭包造成连续写入丢失

- 位置：`useHealthSystem.ts#mutate`
- 问题：所有 mutation 都以当前 render 捕获的 `state` 计算。一次事件循环中连续调用两次，第二次仍以旧状态写入，覆盖第一次。
- 影响：快速杯量、批量操作、保存身高后保存身体记录等路径可能静默丢记录。
- 决定：必须修复。以同步 ref 作为事务基线，并加入表单级幂等键。

## Important

### I-01 God component / hook 与规则散落

- 位置：`HealthModule.tsx` 836 行、`useHealthSystem.ts` 610 行。
- 问题：四子系统 UI、计时、下载、字段转换集中于单组件；校验、导入和领域写入集中于单 hook，难以隔离测试。
- 决定：拆出领域校验/备份预检/休息计时与子视图边界；hook 保留协调职责。

### I-02 输入规则不完整

- 水、睡眠、活动、精力、训练各模式缺少 0/负数/极端值校验；更正身体记录绕过新增校验；餐食无 500/300 字边界；照片无 MIME/大小验证。
- 决定：领域层集中校验，极端但可记录值返回中性复核提示，非法值拒绝。

### I-03 日期与趋势窗口不正确

- `today` 通过 UTC ISO 截取，Asia/Shanghai 临界时刻会归到前一天；趋势没有真正限制 7/30/90 天窗口，覆盖率把记录跨度当窗口，容易把稀疏数据误判为可比。
- 决定：增加本地日期键、明确 cutoff、0 与缺失分离测试。

### I-04 草稿与休息计时不可恢复

- 草稿仅 React state；休息计时仅剩余秒数，切后台/刷新/系统时间变化后失真；没有暂停、延长、跳过、到点状态。
- 决定：持久化草稿；倒计时用目标时间而非每秒递减值，并提供完整控制和 aria-live。

### I-05 删除/恢复不完整

- UI 只显示身体和餐食垃圾箱；无永久删除确认；照片永久删除/孤儿清理不存在；训练项目无法归档。
- 决定：补全四类垃圾箱、永久删除与媒体清理、项目归档保留历史。

### I-06 关闭指标未真正隐藏

- 仅精力受偏好控制，睡眠、饮水、活动仍显示；切换活动模式没有入口。
- 决定：所有快速入口依偏好显示，历史数据不删除；增加步数/活动分钟切换。

### I-07 训练领域能力未完整映射

- 类型能表达分段/组类型/单侧/额外或辅助重量，但快速记录 API 和 UI 丢弃这些字段；复制草稿无恢复/放弃/结束；重复结束不幂等。
- 决定：扩展标准输入结构、深拷贝验证、草稿生命周期与摘要派生测试。

### I-08 媒体生命周期与容量风险

- 页面不读取照片；导出全量 Blob→DataURL 同时驻留内存；IndexedDB 错误关闭不完整；无孤儿清理、数量/单张大小上限。
- 决定：限制 3 张/单张 8 MiB/支持 MIME，补读取、永久删除与孤儿清理；压力测试 50 张受控小图。

### I-09 缺少保存/撤销/导入状态反馈

- 多数保存后只有计数变化；错误未关联字段；软删除无即时恢复动作；导入直接替换，无预检摘要与冲突选择。
- 决定：增加 `aria-live` 状态、确认/预检 UI、明确替换策略与恢复入口。

## Suggestions

- 大历史列表在 1,000 条下仍会一次性渲染，V1 可先限制页面展示最近 50 条并保留完整导出。
- `HealthModule` 后续可继续按四个子域拆文件；本轮优先将领域规则与计时从 UI 分离并保证关键路径可测。
- ZIP 是 PRD 中的推荐实现而非当前明确格式承诺；本轮以带 manifest、校验和、结构与媒体的单文件 JSON bundle 交付，并在验收矩阵明确格式，不冒充 ZIP。
