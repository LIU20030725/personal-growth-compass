## 结论

当前实现完整保留了本地记录、历史、趋势、五种训练数据结构、逐组记录、休息计时、复制上次、导出/导入与垃圾箱，但四个核心页面的任务模型均未达到 revision 2083。此前版本主要调整了首页层级与视觉语言，未完成训练编排、营养台账、日常提醒和身体围度四个关键闭环，因此不能视为 UI 优化完成。

## 必须保留的既有能力

- 身体：身高、体重、体脂率、BMI 快照、历史更正、趋势、删除与恢复。
- 饮食：文字、照片、餐次、时间、饱腹感、备注、媒体本地存储与导出。
- 日常：饮水、睡眠、步数或活动时长、指标开关、历史数据保留。
- 训练：距离计时、重量次数、自重次数、定时组数、时长训练；高级字段；逐组记录；复制上次；休息计时；草稿；历史。
- 数据：本地优先、事务恢复、单文件 JSON bundle 导入导出、垃圾箱、非医疗提示。

## 追踪原则

1. 新能力以可选字段和可迁移默认值扩展，不重写或丢弃旧记录。
2. 每个页面仅有一个主动作：首页快速记录；训练开始；饮食添加食物；日常记录；身体新增数据。
3. 默认界面保持轻量，高级训练字段、提醒设置、自定义食物通过渐进披露出现。
4. 所有健康提示只说明记录事实和复核建议，不做诊断、治疗、风险或因果判断。
