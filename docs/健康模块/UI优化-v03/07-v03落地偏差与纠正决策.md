# 健康模块 v03：落地偏差与纠正决策

日期：2026-08-15

## 为什么上一版仍然显得“没有优化”

上一轮审计正确识别了“四子系统平权、卡片过多、子页面模板化、训练主次颠倒”等问题，但生产实现主要完成了配色、圆角、边框、弹窗和可访问性修补，没有把审计结论落实成明显可见的结构变化。当前 `5174` 实际页面因此仍有以下问题：

1. 首页仍是标题、今日横条、四张等权入口卡、两张说明卡的后台面板结构；用户视线没有明确落点。
2. “今日概览”只是一句空态文字，没有把饮水、餐食、活动/训练这些事实变成可扫读的状态。
3. 四个模块虽然尺寸缩小，但仍以相同卡片和相同视觉重量同时出现，和审计要求不一致。
4. 身体、饮食、日常和数据页继续共用“左表单、右历史”的数据库式模板，页面性格和任务差异没有体现。
5. 训练页把“创建训练项目”放在主栏左侧，而真正的逐组记录位于右侧；所有直接按钮又大面积使用柔黄，导致主动作失焦。
6. 页面内容集中在顶部，桌面端下方留下大面积无意义空白；卡片、边框和阴影数量过多，呈现出模板化、缺少编辑感的视觉。

这不是用户偏好差异，而是“设计决策与实现不一致”。本轮不再把上一版作为已完成的视觉优化。

## 纠正后的设计锁

- 首页采用不对称的“今日指挥区”：深鼠尾草事实面板承担唯一视觉焦点，柔黄只用于“一键记录”。
- 今日事实直接展示饮水、餐食和训练三项状态；没有记录时显示“未记录”，不把缺失伪装成 0 分或失败。
- 四个模块保留为第二层紧凑导航，不再使用四张独立白卡与主任务争夺注意力。
- 周/月回看和数据管理收成一条低视觉重量的工具带，避免再造两张说明卡。
- 子页根据任务区分层级：记录表单是明确操作区，历史/趋势是安静阅读区；不再让两个白卡完全等权。
- 训练页将“当前训练/逐组记录”放在宽主栏，“创建项目”移动到窄辅助栏；普通按钮恢复中性，只有保存或创建使用柔黄。
- 保留全部健康数据结构、导入导出、修订链、垃圾箱、五种训练模式、进阶字段和本地持久化，不以视觉简化删除功能。

## 本轮验收标准

1. 用户只看一眼首页就能指出唯一主动作是“一键记录”。
2. 首页首屏中，四模块入口明显低于今日状态与主动作，不再平权抢占注意力。
3. 身体页与训练页不再呈现相同的双白卡模板；训练当前任务在桌面端位于主栏左侧。
4. 同一屏不出现三个以上同等级柔黄按钮。
5. 1440、1024、390 三档无横向溢出；移动端今日状态和主动作在首屏内可见。
6. 所有原有组件测试、全仓测试、构建和 axe 基线继续通过。
