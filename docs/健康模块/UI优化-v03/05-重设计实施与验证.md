# 健康模块 v03 重设计实施与验证

日期：2026-08-15
分支：`codex/health-ui-v03`
基线：`origin/main@e82e31b`

## 已实施

- 首页改为“今日概览 → 一键记录 → 四类紧凑入口 → 周/月回看 → 数据管理”，柔黄只突出“一键记录”。
- 一键记录使用可访问对话框，覆盖饮水、睡眠、餐食、身体和训练；支持 Esc、焦点约束和关闭后返回触发按钮。
- 今日餐食、训练、日常记录按本地日界统计；累计历史不再伪装成“今日”。
- 身体页提供当前输入的 BMI 预览；更正改为站内表单，展示原值并保留修订链语义。
- 日常页把低频指标管理默认收起；关闭指标仍明确保留历史。
- 训练页增加“选择项目 → 逐组记录 → 结束摘要”的阶段提示，当前项目、草稿、计时、高级字段和历史全部保留。
- 导入由粘贴 JSON 改为选择本应用导出的 JSON bundle，之后仍执行原有预检、摘要、确认整体替换和事务回滚。
- 归档、导入替换和永久删除统一使用站内确认对话框，不再调用 `window.prompt` / `window.confirm`。
- 子页面切换后回到模块顶部，避免移动端从首页下方入口进入时落在表单中段。
- 全局品牌与顶栏任务按钮补齐最小 44×44px 目标；其余模块功能和布局未改变。
