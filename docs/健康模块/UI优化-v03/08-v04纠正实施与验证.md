# 健康模块 v04 纠正实施与验证

日期：2026-08-15
基线：`8774dce`

## 纠正结果

本轮将“换肤式优化”纠正为结构重设计，保留全部既有健康功能与数据能力。

### 首页

- 用不对称的今日指挥区替代原有横向空态卡：饮水、餐食和训练成为可扫读的事实摘要。
- 深鼠尾草面板形成唯一视觉焦点；柔黄只保留给“一键记录”。
- 根据真实状态展示“未完成训练草稿 / 最近身体记录 / 尚无身体记录”，提供一个上下文动作。
- 四个子系统从四张独立白卡改为同一组内的二级导航，不再与今日主任务平权。
- 周/月回看和数据管理合并为低权重工具带，减少重复卡片、阴影和视觉噪声。

### 身体与饮食

- 记录表单作为明确操作区；历史/趋势改为开放阅读区，不再是两张完全等权白卡。
- 身体表单在桌面端使用两列字段编组，BMI 与保存动作保持全宽；移动端回到单列。
- 餐食继续保留文字、照片、餐次与饱腹感，空时间线不展示虚构内容。

### 日常健康

- 把一条长表单拆为饮水、睡眠、活动和可选精力的独立记录区。
- 已启用项目按两列排布，三项时末项自动占满一行；移动端自然回到单列。
- 指标管理保持窄辅助区和默认收起，关闭指标仍不删除历史。

### 运动健身

- 桌面端将当前训练/逐组记录放到宽主栏左侧；新建训练项目移动到窄辅助栏。
- 训练步骤、当前动作、进阶字段、组记录和保存动作形成从上到下的单一流程。
- “展开进阶”“添加一组”“休息”恢复为中性动作；柔黄仅用于创建项目和保存本次训练。
- 移动端先展示当前训练，再展示项目设置，所有原有五模式与高级字段继续保留。
