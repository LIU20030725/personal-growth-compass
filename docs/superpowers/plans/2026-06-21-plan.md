# 个人成长进步罗盘 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Build a PWA React app where users track personal growth across 4 life systems via a game-like character panel with compass dashboard, skill tree, streak tracking, and goal contracts.

**Architecture:** React 18 + TypeScript + Vite SPA. Zustand stores persisted through a swappable StorageAdapter interface (localStorage v1). Four system pages with nested submodules, SVG compass dashboard, gamification engine computed client-side.

**Tech Stack:** React 18, TypeScript, Vite, React Router v6, Zustand, Recharts, Framer Motion, CSS Modules, vite-plugin-pwa, Vitest + React Testing Library
