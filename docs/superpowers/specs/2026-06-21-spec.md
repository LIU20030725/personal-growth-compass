# 个人成长进步罗盘 - 设计规格书

> 日期：2026-06-21 | 状态：已确认 | 目标平台：Web（PWA，后续移植手机 App）

## 一、项目概述

一个网页应用（PWA），以游戏化角色状态面板风格，可视化记录和追踪个人在四大系统的成长数据。帮助用户看清自身优点和不足，通过目标契约机制驱动持续进步。

**分阶段交付：**
- 第一阶段：Web PWA（桌面 + 移动端浏览器），纯前端 + localStorage
- 第二阶段：通过 Capacitor 封装为 iOS/Android App，复用全部代码和数据层抽象

## 二、技术栈

- **框架**：React 18 + Vite + TypeScript
- **状态管理**：Zustand（存储层抽象为适配器接口，v1 localStorage，v2 Capacitor Preferences / SQLite）
- **路由**：React Router v6
- **图表**：Recharts（SVG 渲染，Web/App 通用）
- **动画**：Framer Motion（Web 动画，App 版降级为 CSS transition）
- **PWA**：vite-plugin-pwa（Service Worker 离线缓存 + manifest.json 可安装）
- **样式**：CSS Modules + CSS Custom Properties（主题变量），mobile-first 响应式
- **股票行情**：免费 API（Alpha Vantage 或 Yahoo Finance）
- **数据存储抽象**：自定义 StorageAdapter 接口，解耦 Zustand persist middleware 与具体存储实现
- **App 封装**：Capacitor（非 React Native），保留所有 Web 代码
- **部署**：Phase 1 Vercel/Netlify；Phase 2 App Store / Google Play

## 三、移动端可移植性设计（贯穿全程）

### 存储层抽象
```
interface StorageAdapter {
  getItem(key: string): Promise<string | null>;
  setItem(key: string, value: string): Promise<void>;
  removeItem(key: string): Promise<void>;
}
```
- Phase 1：LocalStorageAdapter 实现
- Phase 2：CapacitorPreferencesAdapter 实现，可无缝切换
- Zustand persist middleware 通过适配器接口注入，业务代码不感知底层存储

### UI 适配
- CSS 断点：<768px 移动端 / 768~1024px 平板 / >1024px 桌面
- 移动端罗盘首页简化为垂直堆叠（扇形图改为竖排卡片）
- 触控优先：最小点击区域 44×44px，滑动手势导航
- 所有表单控件使用原生 input/select，避免自定义组件在移动端行为不一致

### Phase 2 预留（不在 Phase 1 实现）
- 本地推送通知（目标截止提醒、连续打卡提醒）
- 生物识别锁定（Face ID / 指纹）
- 健康数据同步（Apple Health / Google Fit 自动导入运动数据）

## 五、激励系统设计（三层目标契约）

**核心理念**：升级不再是目标，而是副产物。真正驱动用户的是"看见自己的进步 + 兑现给自己的奖励"。

### 第一层：短期反馈 - 连续打卡（Streak）
- 习惯模块、运动模块支持连续打卡天数展示
- 火焰图标随连续天数变化（小火苗 -> 烈焰）
- 断掉则熄灭重置，制造正向压力

### 第二层：中期正反馈 - 趋势可视化
- 所有可量化指标提供折线图/趋势视图
- 收入上升、技能等级上升、体重/BMI 趋向目标区间 -> 图表即奖励
- "本月 vs 上月"对比卡片

### 第三层：长期目标契约
- 用户自定义 SMART 目标（如"3 个月内体脂降到 15%"）
- 绑定自我奖励（如"买 Switch 2"、"吃一顿大餐"）
- 目标进度通过关联数据自动计算（体脂目标关联 BMI 最新值）
- 目标达成后弹出庆祝动画 + 展示兑现奖励提示
- 目标进度条在首页可见

### 等级机制（副产物）
- 等级 Lv.1 ~ Lv.100
- 等级综合计算：各系统数据量 x 活跃频率 x 目标完成率，具体公式在实施计划中细化
- 各系统综合评分（0~100%）= 该系统的加权指标归一化值
- 颜色阈值：>=70% 绿色、40%~69% 黄色、<40% 红色

## 七、首页罗盘布局

- 四象限扇形图，面积比例反映该系统综合评分
- 中心圆显示等级
- 扇形颜色：绿色=良好、黄色=关注、红色=待改善
- 点击扇形进入对应系统
- 扇形外圈标记点：最近解锁的成就
- 下方：最近活动时间线 + 目标进度条
- 移动端（<768px）：扇形图改为竖排四张系统概览卡片

## 八、能力树（Skill Tree）

参考游戏天赋树/科技树设计：
- 每个节点 Lv.1~Lv.10，表示掌握深度
- 子节点解锁条件：前置节点 >= 指定等级 + 用户标记"已掌握"
- 广度指标：已解锁节点数 / 深度指标：节点平均等级
- 支持"专精路线"和"博学路线"两种成长路径

## 九、关键设计原则

### 贴近生活，不玄幻
- 所有指标必须：可手动录入、可量化对比、反映真实状态
- 禁止虚构指标（精神力值、综合战斗力等）
- 情绪系统只做 1-10 分自评 + 文字记录

### 股票自动更新
- 用户填入股票代码 + 股数，系统拉取行情 API 自动计算持仓市值
- 绿色向上箭头红色向下箭头显示涨跌
- API 失败时使用上次缓存值 + 标记"更新失败"

### 成就系统
- 预定义成就表（约 15-20 个成就），数据变更时自动检测触发
- 解锁时弹出 Framer Motion 动画，收入全局成就墙页面
- 成就分三类：里程碑型、累计型、连续型
- 具体成就清单在实施计划中定义

## 十、非功能性要求

- **PWA**：Service Worker 离线缓存，manifest.json 可安装到主屏幕
- **响应式设计**：mobile-first，三个断点（<768 / 768-1024 / >1024）
- **触控友好**：最小点击区域 44×44px，原生表单控件
- **存储抽象**：StorageAdapter 接口，Phase 1 localStorage，Phase 2 可切换
- **无后端依赖**：纯前端应用，无需登录/注册
- **数据隐私**：所有数据纯本地存储，不上传任何服务器
- **App 可移植**：不依赖浏览器专有 API，代码结构支持 Capacitor 封装
