# 个人成长进步罗盘 - 设计规格书

> 日期：2026-06-21 | 状态：已确认

## 一、项目概述

一个网页应用，以游戏化角色状态面板风格，可视化记录和追踪个人在四大系统的成长数据。帮助用户看清自身优点和不足，通过目标契约机制驱动持续进步。

## 二、技术栈

- **框架**：React 18 + Vite
- **状态管理**：Zustand（数据通过 middleware 自动持久化到 localStorage）
- **路由**：React Router v6
- **图表**：Recharts
- **动画**：Framer Motion
- **股票行情**：免费 API（Alpha Vantage 或 Yahoo Finance 非官方接口）
- **部署**：先本地开发（npm run dev），后续部署 Vercel/Netlify
- **数据存储**：localStorage，key 前缀 pg_

## 四、激励系统设计（三层目标契约）

**核心理念**：升级不再是目标，而是副产物。真正驱动用户的是"看见自己的进步 + 兑现给自己的奖励"。

### 第一层：短期反馈 - 连续打卡（Streak）
- 习惯模块、运动模块支持连续打卡天数展示
- 火焰图标随连续天数变化（小火苗 → 烈焰）
- 断掉则熄灭重置，制造正向压力

### 第二层：中期正反馈 - 趋势可视化
- 所有可量化指标提供折线图/趋势视图
- 收入↑、技能等级↑、体重/BMI 趋向目标区间 → 图表即奖励
- "本月 vs 上月"对比卡片

### 第三层：长期目标契约
- 用户自定义 SMART 目标（如"3 个月内体脂降到 15%"）
- 绑定一个自我奖励（如"买 Switch 2"、"吃一顿大餐"）
- 目标进度通过关联数据自动计算（体脂目标关联 BMI 最新值）
- 目标达成后弹出庆祝动画 + 展示兑现奖励提示
- 目标进度条在首页可见

### 等级机制（副产物）
- 等级 Lv.1 ~ Lv.100
- 等级综合计算：各系统数据量 × 活跃频率 × 目标完成率，具体公式在实施计划中细化
- 各系统综合评分（0~100%）= 该系统的加权指标归一化值，用于罗盘扇形大小和颜色判定
- 综合评分阈值：>=70% 绿色、40%~69% 黄色、<40% 红色

## 六、首页罗盘布局

- 四象限扇形图，面积比例反映该系统综合评分
- 中心圆显示等级
- 扇形颜色：绿色=良好、黄色=关注、红色=待改善
- 点击扇形 → 进入对应系统
- 扇形外圈标记点 → 最近解锁的成就
- 下方：最近活动时间线 + 目标进度条

## 七、能力树（Skill Tree）

参考游戏天赋树/科技树设计：
- 每个节点 Lv.1~Lv.10，表示掌握深度
- 子节点解锁条件：前置节点 >= 指定等级 + 用户标记"已掌握"
- 广度指标：已解锁节点数 / 深度指标：节点平均等级
- 支持"专精路线"和"博学路线"两种成长路径

## 八、关键设计原则

### 贴近生活，不玄幻
- 所有指标必须满足：可手动录入、可量化对比、反映真实状态
- 禁止虚构指标（精神力值、综合战斗力等）
- 情绪系统只做 1-10 分自评 + 文字记录，不做伪科学计算

### 股票自动更新
- 用户填入股票代码 + 股数，系统拉取行情 API 自动计算持仓市值
- 绿色↑红色↓显示涨跌
- API 失败时使用上次缓存值 + 标记

### 成就系统
- 预定义成就表（约 15-20 个成就），数据变更时自动检测触发
- 解锁时弹出 Framer Motion 动画，收入全局成就墙页面
- 成就分三类：里程碑型、累计型、连续型
- 具体成就清单在实施计划中定义

## 九、非功能性要求

- 响应式设计，桌面端为主，移动端可用
- localStorage 自动持久化，无需登录
- 所有数据纯本地存储，隐私安全
