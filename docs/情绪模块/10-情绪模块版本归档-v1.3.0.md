# Dice Life 情绪模块版本归档 v1.3.0

> 归档日期：2026-08-13  
> 开发分支：`codex/emotion-module`  
> 版本范围：情绪表情图谱与网页版音乐快捷收藏

## 1. 本次变更

- 表情扩展为 18 种，按“愉悦 / 平稳 / 低能量 / 高压力”四组展示。
- 参考确认稿重绘为低饱和渐变圆脸、CSS 五官和情绪标记，不依赖系统 Emoji，缩放表现一致。
- 新增“清醒”，并将“悲伤”归入低能量；旧记录使用未知情绪 ID 时安全回退到“平静”。
- 音乐入口收纳为与“语音”并列的按钮，默认不展开表单。
- 用户粘贴网易云音乐、QQ 音乐或其他音乐网页的分享内容后，系统提取安全的 `http/https` 链接，并尽量识别歌曲名、歌手和平台。
- 保存音乐不再要求用户填写歌曲名、歌手或可播放地址；历史记录中已有可播放地址仍保持站内播放兼容。
- 新记录的音乐卡通过“去听这首歌”打开原音乐网页；外链使用新标签页及 `noopener noreferrer`。
- 音乐面板支持初始焦点、Esc 关闭与焦点返回，危险或畸形链接不会生成可点击入口。

## 2. 兼容性与产品边界

- 数据模型保持 v2，未新增破坏性迁移；原平台链接写入 `sourceUrl`，`playbackUrl` 可为空。
- 网易云音乐与 QQ 音乐网页版能否直接开始播放，取决于目标网站的登录、版权和浏览器自动播放策略；本模块保证正确打开用户收藏的原资源页。
- 当前版本为网页版，不尝试唤醒网易云音乐或 QQ 音乐客户端。移动应用阶段可通过系统分享入口、Universal Link / App Link 与平台 Scheme 单独实现。
- 仅根据分享文本做本地解析，无法保证所有平台和所有分享格式都带有完整歌名、歌手；识别不到时仍可保存为安全网页链接。

## 6. 已知限制

- 跨站脚本无法可靠读取网易云音乐或 QQ 音乐页面内部元数据，因此“自动识别”主要依赖用户粘贴的分享文案和 URL；后续如需更高命中率，应由服务端接入合规的平台元数据能力。
- 目标音乐网站可能要求登录，或因地区、版权下架导致资源不可播放；收藏记录仍保留原始链接。
- iOS Safari 与 Android Chrome 的系统字体、真实触控、软键盘和外部网站跳转仍需发布前真机复核。
- 本轮未新增客户端唤醒、系统分享面板、服务端解析或音乐平台授权。
