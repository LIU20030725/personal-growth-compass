# Dice Life 情绪模块 v1.3：表情视觉与音乐快捷收藏设计

> 日期：2026-08-13  
> 状态：已确认，待实施计划  
> 范围：网页版情绪模块；为未来原生手机版保留兼容接口

## 1. 目标

本次更新解决两个体验问题：

1. 情绪表情采用用户确认的分组式圆形渐变脸视觉，提高情绪辨识度，同时延续项目清新、简约、治愈的整体风格。
2. 音乐收藏从常驻的多字段表单改为与图片、视频、语音并列的单一入口。用户只需粘贴一个音乐分享链接，系统自动识别来源和可恢复的信息；保存后点击音乐卡，前往原音乐资源。

## 2. 方案比较与决策

### 2.1 音乐录入方案

| 方案 | 优点 | 缺点 | 决策 |
|---|---|---|---|
| 保留歌曲名、歌手、平台链接、播放地址等字段 | 信息最完整 | 操作重、页面杂乱，用户需理解技术字段 | 不采用 |
| 只粘贴分享链接，前端本地识别 | 操作最轻、无需后端、隐私边界清楚 | 只能保证识别平台和 URL 中/分享文本中的部分信息 | 当前网页版采用 |
| 后端抓取页面元数据或接第三方音乐 API | 可自动获得歌名、歌手、封面 | 有跨域、反爬、稳定性、版权、接口授权和隐私成本 | 未来按授权评估 |

### 2.2 播放与跳转方案

当前网页版以“去原平台听歌”为主，不承诺站内播放：

- 收藏内容带安全的 `http/https` 原资源链接。
- 点击音乐卡或“去听这首歌”按钮，在新标签页打开原链接。
- 手机浏览器是否进一步唤起网易云/QQ 音乐客户端，由音乐平台链接、系统设置和客户端安装状态决定。
- 未来原生 App 复用同一原链接，通过 Universal Link、App Link 或平台公开深链能力增强客户端唤醒，无需迁移历史数据。

## 3. 情绪表情设计

### 3.1 情绪分组

沿用并明确四个语义分组：

- 愉悦：开心、兴奋、感激、满足。
- 平稳：平静、放松、专注、清醒。
- 低能量：疲惫、无聊、低落、孤独、悲伤。
- 高压力：焦虑、压力、生气、迷茫、撑不住。

如果现有数据中存在旧情绪 ID，则保留 ID 和历史记录，只更新展示配置；不得因视觉升级破坏旧记录。

### 3.2 视觉语言

- 基础形状：圆形柔和渐变脸，五官使用深色矢量/CSS 图形。
- 分组色：愉悦使用暖黄；平稳使用鼠尾草绿或雾蓝；低能量使用低饱和淡紫；高压力使用珊瑚、粉红或红紫。
- 表达方式：依靠五官、眉形、嘴形和一处克制的小装饰表现差异，例如星光、爱心、呼气、感叹号、泪滴或怒气。
- 图一仅作为视觉方向，不将整张参考图裁切为产品素材；每个表情作为独立可缩放组件实现。
- 避免使用系统 Emoji 字体，防止不同系统外观不一致。

### 3.3 使用位置

同一表情组件用于：

- 新建记录的情绪选择器。
- 首页状态问候和日记卡片。
- 心情日历。
- 内容库和记录详情。

尺寸分为 small、medium、large；各尺寸保持同一五官比例。选中状态使用柔黄描边、浅色底和可见焦点环，不只依靠颜色表达。

## 4. 编辑器布局

### 4.1 默认状态

“为这一刻留点什么”区域保持文字输入，其下媒体操作统一为同层按钮：

`图片　视频　语音　音乐`

要求：

- 四个入口高度、圆角、图标尺寸、文字基线和间距一致。
- 桌面端一行排列；390px 优先保持四列，空间不足时允许两列，不产生横向滚动。
- 触控目标不小于 44×44px。
- 音乐表单默认不显示。

### 4.2 点击音乐后的轻量面板

面板只包含：

- 标题：“收藏此刻的歌”。
- 单一输入：“粘贴网易云、QQ 音乐或其他音乐网页链接”。
- “识别”按钮；粘贴合法链接后也可自动触发识别。
- 识别结果预览卡。
- “添加到这一刻”与“取消”。

不再向用户展示或要求填写“可播放地址”。歌曲名称和歌手也不作为必填输入。

## 5. 链接识别与数据流

### 5.1 输入处理

1. 用户粘贴分享文本或纯链接。
2. 系统从文本中提取第一个合法的 `http/https` URL。
3. 根据域名识别平台：网易云、QQ 音乐或其他。
4. 尝试从分享文本、URL 路径和查询参数中提取歌曲名、歌手或资源 ID。
5. 生成预览卡，用户确认后加入当前草稿。

不得接受 `javascript:`、`data:`、`file:`、空白或畸形 URL。重定向后的最终安全性由打开页面的浏览器负责，但本应用只能输出带 `noopener/noreferrer` 的外链。

### 5.2 识别成功

预览优先展示：

- 歌曲名称。
- 歌手。
- 来源平台。
- 封面（仅当存在可信、可直接加载的安全图片地址时）。

### 5.3 部分识别或识别失败

平台或歌曲信息无法读取时仍允许保存链接，不退回多字段表单：

- 能识别平台：显示“网易云音乐收藏”或“QQ 音乐收藏”。
- 不能识别平台：显示“音乐网页收藏”。
- 辅助文案：“暂时没有读到歌曲信息，仍可保存并前往原网页。”
- 操作：“直接保存链接”“重新粘贴”。

网络或解析失败不应阻断情绪记录保存。

## 6. 音乐卡交互

### 6.1 展示

日记、内容库和详情中的音乐卡保持简洁：

- 音乐图标或封面。
- 歌名/降级标题。
- 歌手与平台（有则显示）。
- 外链标识和“去听这首歌”。

### 6.2 点击行为

- 点击整张卡或按钮打开原平台链接。
- 桌面网页使用新标签页，避免丢失 Dice Life 当前状态。
- 移动网页交给操作系统处理该 HTTPS 链接；若平台支持，可能唤醒客户端，否则打开网页。
- 链接为空、非法或历史数据损坏时不导航，显示“链接暂时不可用”。
- 不把“自动播放”作为验收承诺。

## 7. 数据兼容

现有 `EmotionMusicReference` 保持向后兼容：

- `sourceUrl` 继续作为唯一必须持久化的目标资源地址。
- `provider`、`title`、`artist` 是可自动填充的展示信息；解析不到时使用降级值。
- `playbackUrl` 暂时保留以读取历史数据，但新建网页版记录不再要求或生成该字段。
- 既有带 `playbackUrl` 的记录仍可按照原逻辑播放，避免破坏用户数据；新 UI 以原平台跳转为默认策略。
- 为未来原生 App 可增加 `externalId`、`resourceType`、`deepLink` 等可选字段，但不得替换 `sourceUrl`。

## 8. 组件边界

- `EmotionIcon`：只负责根据情绪配置渲染独立矢量/CSS 表情。
- `emotionConfig`：维护分组、标签、颜色、脸型和装饰配置。
- `MusicLinkParser`：纯函数，负责 URL 提取、平台识别、分享文本解析和降级标题。
- `EmotionMusicPicker`：负责单链接输入、识别状态、预览与确认。
- `EmotionMusicCard`：负责安全展示与原平台跳转，不承担解析。
- `EmotionComposer`：管理草稿和打开/关闭音乐面板，不包含平台解析细节。

解析器和 UI 分离，便于未来将本地解析替换为授权后的服务端元数据解析。

## 9. 状态与错误处理

音乐面板状态：空闲、识别中、识别成功、部分识别、输入错误。

- 识别中超过 300ms 显示轻量进度反馈。
- 输入错误在输入框附近说明，不只显示在编辑器顶部。
- 用户关闭音乐面板时，仅清理未确认的音乐临时状态，不影响文字、图片、视频、语音和情绪选择。
- 编辑既有记录时可查看、更换或移除音乐。
- 整个编辑器关闭时继续遵守既有未保存确认和焦点返回行为。

## 10. 可访问性与响应式

- 所有音乐按钮和外链具有清晰可访问名称。
- 情绪选择使用单选语义，宣布标签和选中状态。
- 表情装饰为隐藏语义，避免屏幕阅读器重复朗读。
- 键盘可打开/关闭音乐面板、粘贴链接、确认添加；Escape 返回触发按钮。
- 正文对比度达到 WCAG AA，焦点环清晰。
- 390px、1024px、1440px 均无横向溢出，弹层和固定底栏不遮挡操作。

## 11. 测试与验收

### 自动化

- 18 个情绪 ID 均渲染正确分组、脸型和标签。
- 旧情绪数据展示不回退。
- 纯链接、带文案分享文本、网易云、QQ 音乐、其他网页均可解析。
- 危险协议、空白、畸形 URL 被拒绝。
- 识别失败可以降级保存，不产生必填歌名/歌手错误。
- 新建音乐不要求 `playbackUrl`；历史播放地址仍兼容。
- 音乐面板打开、取消、确认、更换、移除和焦点返回正确。
- 音乐卡安全外链属性和非法链接禁用行为正确。

### 浏览器验收

- 粘贴一条网易云和一条 QQ 音乐分享链接，预览并保存。
- 点击已保存音乐卡，打开原资源网页且 Dice Life 原页面保留。
- 模拟无法识别的信息，验证降级标题仍可保存和跳转。
- 1440×900、1024×768、390×844 检查编辑器、音乐面板、列表、内容库和详情。
- axe serious/critical 为 0；控制台无新增 error/warn。

## 12. 非本期范围

- 网易云或 QQ 音乐私有/非公开 API 接入。
- 绕过版权限制获取音频文件。
- 保证唤醒第三方客户端或保证自动播放。
- iOS Share Extension、Android 系统分享目标或 PWA Share Target。
- 跨设备同步音乐收藏。

这些能力留到原生手机版或正式后端阶段评估。
