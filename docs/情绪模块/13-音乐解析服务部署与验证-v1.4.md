# 情绪模块音乐解析服务部署与验证 v1.4

**日期：** 2026-08-14  
**分支：** `codex/emotion-module`

## 本地运行

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 4175
```

Vite 插件会在开发服务与 `vite preview` 中挂载 `POST /api/music/resolve`，无需密钥。示例：

```bash
curl -X POST http://127.0.0.1:4175/api/music/resolve \
  -H "content-type: application/json" \
  -d '{"url":"https://music.163.com/song?id=1495784933"}'
```

## Serverless 部署

`api/music/resolve.mjs` 是 Node 兼容的 serverless 入口，复用与本地环境相同的处理器。部署平台必须：

- 允许该函数出站访问网易云与 QQ 音乐的公开 HTTPS 元数据端点；
- 将 `/api/music/resolve` 路由到此函数；
- 不配置平台账号、Cookie、Authorization 或音乐版权密钥；
- 生产多实例时，把当前内存限流替换为平台网关限流或共享限流存储。

纯静态托管不会运行 API 函数；此时前端会显示服务不可用，并允许用户仅保存安全链接，完整分享文案仍可离线解析。

## 验证记录

- 真实网易云链接：`song?id=1495784933`。
- 结果：`EVERYTHING`；歌手 `Way Ched / CHANGMO / Coogie / ASH ISLAND / BIBI`；封面正常显示。
- 真实 QQ 链接：`songDetail/0039MnYb0qxYhV`。
- 结果：`晴天`；歌手 `周杰伦`；封面地址按公开专辑 ID 生成。
- 失败降级：上游超时、404、服务不可达时显示明确原因，并仅对安全原链接提供“仅保存链接”。
- 安全夹具：非 HTTP(S)、恶意子域、IP/localhost、凭证、非标准端口、非单曲页面、超大响应、上游重定向、超时、限流均有自动化断言。
- 浏览器控制台：真实网易云识别流程 `error/warn = 0`。

## 已知限制

- 不解析歌单、专辑、播客、搜索页或音频播放地址。
- 网易云与 QQ 的公开元数据结构可能变化；变化时替换对应 provider adapter。
- 出于 SSRF 与 DNS rebinding 边界考虑，服务端不解析短链接；用户可粘贴展开后的官方单曲链接或包含官方单曲链接的完整分享文案。
- 固定上游请求未绑定预解析 IP；风险由“用户不能改变上游 hostname、禁止服务端短链/跳转”控制。若平台 DNS 或运行环境解析链本身被攻破，仍属于残余供应链风险。
- 内存限流已限制客户端桶数量，但 serverless 多实例之间不共享；正式生产需使用平台网关或共享限流服务。
- 服务器不缓存歌曲资料；封面由浏览器直接向平台图片域名加载。
