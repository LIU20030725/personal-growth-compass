# 情绪表情与音乐快捷收藏 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将情绪表情升级为确认的分组渐变圆脸，并把网页版音乐录入改成单分享链接、自动识别、确认收藏和原平台跳转。

**Architecture:** 使用纯函数解析器从分享文本提取安全链接、平台和可恢复的标题/歌手；独立 `EmotionMusicPicker` 管理渐进披露面板，`EmotionComposer` 仅持有草稿。表情继续由 `EmotionIcon` 和配置驱动，保持所有视图复用与历史 ID 兼容。

**Tech Stack:** React 18、TypeScript、CSS、Vitest、Testing Library、jest-axe、Vite。
