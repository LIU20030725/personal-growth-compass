# 情绪模块精细化更新 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成收藏闭环、最近 10 条、重要日、那年今日、音乐引用、统一语音播放与图形化活动选择。

**Architecture:** 将状态升级为可迁移的 v2，并把纯计算放入 `emotionEngine`；新增重要日、音乐、活动图标和播放器组件，避免继续膨胀 `EmotionModule` 与 `EmotionComposer`。所有新视觉规则进入独立 `emotionEnhancements.css`，不覆盖未提交的表情细化样式。

**Tech Stack:** React 19、TypeScript、Vitest、Testing Library、localStorage、IndexedDB、lucide-react。
