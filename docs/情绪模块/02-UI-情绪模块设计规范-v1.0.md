# Dice Life 情绪模块 UI 设计规范 v1.0

> 更新日期：2026-08-02  
> 视觉结论：Daylio 65% × Dice Life 35%  
> 关联文档：[PRD](./01-PRD-Dice-Life-情绪模块-v1.0.md) · [技术实施路线](./03-情绪模块技术实施路线-v1.0.md)

## 1. 设计目标

情绪模块应让用户感觉这里比任务、财富和能力模块更轻、更安静、更容易表达，同时仍然明确属于 Dice Life。

目标关键词：

- 整洁简约；
- 可爱清新；
- 低压力；
- 私密；
- 有生活感；
- 可快速记录；
- 可长期回看。

它不是财务报表换皮，也不是一个嵌入项目的独立绿色 App。

## 2. 视觉组成比例

### 2.1 Daylio 约 65%

情绪模块内容区主要学习：

- 浅紫灰背景；
- 白色大圆角卡片；
- 柔和、克制的悬浮阴影；
- 充足但不过度的留白；
- 圆形情绪角色；
- 胶囊式页签；
- 日期分组记录流；
- 浮动新增按钮；
- 表单逐步展开，先情绪、再活动、最后内容。

### 2.2 Dice Life 约 35%

继续保留：

- 全局顶部栏；
- 左侧角色与系统导航；
- Dice Life 品牌标识；
- 黄色主品牌和主操作；
- Bricolage Grotesque / Bebas Neue 字体体系；
- 中文标题 + 英文微标签；
- 当前项目主容器宽度和响应式骨架；
- 真实成长、恢复与复盘的产品语义。

### 2.3 允许的模块特例

情绪模块内部允许弱化全局 `STYLE.md` 中的以下规则：

- 主内容卡不强制 2px 黑色硬边框；
- 主内容卡可使用 20—24px 大圆角；
- 允许柔和阴影代替实体硬阴影；
- 模块页签可使用胶囊式容器；
- 主新增按钮可使用圆形浮动形式。

这些特例只作用于情绪模块内部。全局顶栏、侧栏和其他模块不跟随改变。

## 3. 品牌色与情绪色

### 3.1 核心规则

> 项目身份看黄色，具体感受看情绪色。

黄色负责：

- Dice Life Logo；
- 当前全局模块导航；
- 选中的模块内页签；
- “记录感受”主按钮；
- 焦点与重要操作提示；
- 关键确认反馈。

情绪色负责：

- 情绪角色背景；
- 情绪名称；
- 对应活动的小范围浅色标签；
- 心情日历中的日期情绪图标；
- 当前状态卡中的局部氛围。

绿色不得承担整个情绪模块的品牌色或通用选中状态。

### 3.2 设计令牌

```css
:root {
  /* 继承全局 */
  --emotion-brand: #ffd700;
  --emotion-brand-ink: #705d00;
  --emotion-ink: #191c1d;

  /* 模块表面 */
  --emotion-canvas: #f2f1f7;
  --emotion-surface: #ffffff;
  --emotion-surface-muted: #f8f7fb;
  --emotion-divider: #e5e3eb;
  --emotion-text-secondary: #62616c;

  /* 情绪浅色，只作局部使用 */
  --mood-joy: #ffe38a;
  --mood-calm: #ccefe3;
  --mood-neutral: #dfe8ef;
  --mood-low-energy: #e4def5;
  --mood-stress: #f5d1c7;
  --mood-sad: #dbe7f3;

  /* 阴影 */
  --emotion-shadow-sm: 0 6px 18px rgba(42, 42, 58, 0.08);
  --emotion-shadow-md: 0 12px 30px rgba(42, 42, 58, 0.11);
  --emotion-focus: #8b6500;
}
```

最终实现优先复用全局颜色变量，新增令牌集中放在情绪模块样式根节点，禁止在组件内散落临时 Hex 值。

### 3.3 对比度

- 正文与背景对比度至少 4.5:1；
- 大字号标题至少 3:1；
- 浅色情绪底上使用深色文字，不使用浅绿字叠浅绿底；
- 情绪不能只靠颜色区分，必须同时显示图标和名称；
- 黄色按钮使用深棕或黑色文字，不使用白字。

## 4. 字体与信息层级

沿用项目字体：

```yaml
display: Bebas Neue
body: Bricolage Grotesque
fallback: system-ui, sans-serif
```

推荐字号：

| 层级 | 桌面 | 移动 | 用途 |
|---|---:|---:|---|
| 页面标题 | 40px | 32px | 情绪状态 |
| 当前情绪 | 32px | 28px | 平静、开心等 |
| 卡片标题 | 20px | 18px | 今天，8 月 2 日 |
| 记录正文 | 16px | 16px | 日记内容 |
| 标签 | 14px | 14px | 活动、页签 |
| 微标签 | 12px | 12px | MIND STATUS、CURRENT STATE |

规则：

- 正文行高 1.5—1.65；
- 日记详情每行约 55—75 个中文字符的视觉宽度；
- 时间使用等宽数字或 `font-variant-numeric: tabular-nums`；
- 不使用 12px 以下的正文；
- 英文微标签用于建立 Dice Life 身份，不大面积使用全大写英文。

## 5. 布局

### 5.1 全局骨架

- 桌面继续使用 64px 顶栏和 256px 左侧栏；
- 情绪模块只替换 `app-shell` 内部内容；
- 不新增第二套全局侧栏；
- 主内容最大宽度沿用项目 1200px；
- 情绪模块背景可在内容区内铺设 `--emotion-canvas`，与其他页面形成温和区分。

### 5.2 桌面布局（≥1101px）

```text
页面标题 + 记录感受按钮
模块页签：日记 / 内容库 / 心情日历
当前状态卡（全宽）
今日与历史记录卡（全宽列表）
```

- 页面左右内边距 24px；
- 模块标题与页签间距 20—24px；
- 卡片纵向间距 20px；
- 当前状态卡最小高度 200px；
- 记录行使用“情绪图标 / 内容 / 可选媒体缩略图”三列；
- 记录正文区域优先扩展，媒体缩略图固定在 120—160px。

### 5.3 平板布局（681—1100px）

- 继承项目横向系统导航；
- 内容宽度使用 `min(100% - 32px, 900px)`；
- 当前状态卡保持横向；
- 记录媒体缩略图降为 96—120px；
- 内容库使用双列瀑布式规则网格，不使用真正高度不可控瀑布流。

### 5.4 移动布局（≤680px）

- 页面单列；
- 当前状态卡改为上下或紧凑横向布局；
- 内容卡圆角 20px；
- 左右页面边距 16px；
- 页面底部提供模块级导航：日记、内容库、日历；
- 圆形新增按钮固定在模块底部导航右侧或上方；
- 必须为项目全局导航和安全区预留空间，避免双层固定导航遮挡内容；
- 新增记录使用全屏页或底部抽屉，优先全屏页以避免长表单嵌套滚动；
- 禁止横向滑动切页，避免与系统返回手势冲突。

### 5.5 断点验收

必须检查：375px、680px、768px、1024px、1440px。任何断点不得出现横向滚动、固定按钮遮挡记录或日历日期错位。

## 6. 页面规范

### 6.1 日记页

结构：

1. 页面标题与新增按钮；
2. 胶囊页签；
3. 当前状态卡；
4. 按日期分组的记录列表；
5. 空状态。

当前状态卡：

- 白色大圆角卡；
- 左侧或中部展示情绪角色；
- 右侧展示“我现在”、情绪名称、活动、时间；
- 只有情绪角色区域使用情绪色；
- 当天无记录时不展示昨日状态；
- 空状态文案：“今天还没有记录，想留下现在的感受吗？”

记录卡：

- 每个日期组用一张白卡承载；
- 同组记录之间使用浅分隔线；
- 情绪图标 48—64px；
- 时间紧邻情绪名称；
- 活动用浅色小标签或点分隔文字；
- 图片/视频仅展示一个主缩略图和剩余数量；
- 语音展示播放按钮、波形占位和时长；
- 整行可点击，更多菜单必须有明确 `aria-label`。

### 6.2 新增记录页

交互顺序严格保持：

```text
情绪单选 → 活动多选 → 文字 → 图片/视频/语音 → 保存
```

情绪选择：

- 按愉悦、平稳、低能量、高压力分组；
- 图标与名称同时出现；
- 每项视觉尺寸 64—76px，触控区域不小于 48px；
- 选中后出现黄色外圈或黄色小勾，不能只改变情绪底色；
- 同时只能选中一项；
- 不使用系统字体 Emoji 作为最终资产。

活动选择：

- 采用圆角标签；
- 支持多选；
- 未选为白底灰边；
- 选中为淡黄色底、深色文字和勾选图标；
- 相邻触控目标至少间隔 8px。

内容输入：

- 文本框始终有可见标题“写下此刻感受”；
- 不只使用 placeholder 充当标签；
- 图片、视频、语音按钮使用统一 Lucide 或原创 SVG 线性图标；
- 权限、超限和格式错误紧邻对应区域展示；
- 保存按钮是页面唯一主 CTA；
- 长媒体处理时显示进度，按钮进入 loading 并禁止重复点击。

### 6.3 内容库

- 顶部页签：全部、日记、媒体；
- “珍藏”作为筛选开关，不与主分类并列成第四页签；
- 全部使用双列内容卡；
- 日记可使用双列摘要卡或单列列表，桌面优先双列；
- 媒体使用等宽网格；
- 视频必须显示播放标识和时长；
- 语音在“全部”中使用音频卡，不混入“媒体”；
- 每张卡显示日期和来源情绪；
- 点击后打开来源记录详情；
- 图片使用 `aspect-ratio` 预留空间，避免加载造成布局跳动。

### 6.4 心情日历

- 月份标题居中，前后月按钮触控区域至少 44px；
- 一周从项目本地化规则决定，首版采用周一开始；
- 每个日期格展示日期数字；
- 有记录时展示当天最后情绪图标；
- 多条记录用数字角标显示数量；
- 今天使用黄色细环；
- 选中日期使用淡黄色背景；
- 不能只用色块表示情绪；
- 月历下方直接显示选中日期的记录摘要；
- 空日期文案保持中性，不显示断签或失败。

### 6.5 记录详情

- 顶部提供清晰返回路径；
- 展示完整情绪、活动、时间和内容；
- 图片支持点击查看大图；
- 视频使用原生控制条；
- 语音支持播放、暂停和时长；
- 编辑为次级按钮；
- 删除放入更多菜单底部并使用危险色；
- 删除需要确认，完成后提供撤销 Toast；
- 从内容库进入时定位到被点击的内容。

## 7. 情绪角色与图标规范

### 7.1 设计语言

情绪图标参考微信状态的优点：

- 用图形隐喻表达感受；
- 形象简单，一眼可识别；
- 图标与情绪名称共同出现；
- 同一套角色保持一致脸型、线条和体积；
- 允许植物、天气、气球、电量等符号参与表达。

不得直接临摹或提取微信状态素材。

### 7.2 资产要求

- 最终使用原创 SVG 或高分辨率 WebP；
- 统一画布和安全边距；
- 64、96、160px 三个显示级别保持可识别；
- 同层图标线宽一致；
- 导航、播放、删除等结构性图标使用 Lucide，不使用 Emoji；
- Emoji 风格仅用于情绪角色，不用于系统控制。

### 7.3 状态

- 默认：浅色圆形底；
- Hover：轻微提高阴影，不改变布局尺寸；
- Pressed：透明度或缩放到 0.98，持续 80—120ms；
- Selected：黄色外圈 + 勾选标识；
- Focus：3px 可见焦点环；
- Disabled：仅在保存处理中使用，不禁用情绪本身。

## 8. 圆角、阴影与间距

```yaml
radius:
  page-card: 24px
  sub-card: 18px
  input: 14px
  pill: 999px
  media-thumbnail: 14px

shadow:
  small: 0 6px 18px rgba(42,42,58,.08)
  medium: 0 12px 30px rgba(42,42,58,.11)
  floating-action: 0 10px 24px rgba(112,93,0,.24)

spacing:
  xs: 4px
  sm: 8px
  md: 16px
  lg: 24px
  xl: 32px
  section: 48px
```

同级组件必须使用同一阴影级别。禁止随机增加投影、模糊和圆角。

## 9. 动效

- Hover / Focus / Press：150—200ms；
- 抽屉或详情进入：200—300ms；
- 保存成功：简短勾选或淡入，不超过 400ms；
- 动效只使用 `transform` 和 `opacity`，避免动画宽高引发布局抖动；
- 列表新增可轻微淡入上移；
- 页面跳转维持明确前进/返回方向；
- 支持 `prefers-reduced-motion`，关闭位移与缩放，仅保留必要透明度变化；
- 动画不能阻止点击或保存。

## 10. 响应、反馈与异常

- 点击反馈应在 100ms 内出现；
- 异步保存超过 300ms 显示进度；
- 保存成功 Toast 自动消失时间 3—5 秒；
- 错误信息必须说明原因和解决方法；
- 文件超限应明确显示文件名、限制和移除入口；
- 麦克风权限错误使用图标 + 文案，不只使用红色；
- 离开未保存表单时弹出确认；
- 媒体加载失败保留固定占位，避免页面重排。

## 11. 无障碍

- 所有按钮和可点击卡片支持键盘；
- 焦点顺序与视觉顺序一致；
- 图标按钮有 `aria-label`；
- 当前页签使用 `aria-selected`；
- 情绪单选使用 `radiogroup` 语义；
- 活动多选使用复选或 `aria-pressed`；
- 错误区域使用 `role="alert"` 或 `aria-live`；
- 情绪图片有描述性替代文本，如“平静情绪角色”；
- 装饰叶片等使用空替代文本；
- 触控目标至少 44×44px，移动端建议 48×48px；
- 正文对比度至少 4.5:1；
- 支持浏览器 200% 缩放不丢失内容；
- 色彩不是唯一信息来源。

## 13. 禁止事项

- 不让绿色成为情绪模块通用主色；
- 不把所有卡片恢复成财务模块式黑色硬边报表；
- 不直接复制 Daylio 或微信的品牌、图标和插画；
- 不使用大面积渐变和玻璃拟态；
- 不用情绪色代表成功、失败或危险等级；
- 不在情绪页面显示 XP、骰子、排名和综合情绪分；
- 不使用系统 Emoji 充当导航、录音、删除等结构性图标；
- 不使用低对比度浅灰正文；
- 不依靠 Hover 才能发现操作；
- 不让固定新增按钮遮挡最后一条记录；
- 不用空日历制造断签压力。

## 14. 设计验收清单

- [ ] 黄色明确承担品牌、选中态与主 CTA；
- [ ] 绿色只用于具体情绪或局部内容；
- [ ] Daylio 式柔和卡片与留白占内容区主要视觉；
- [ ] 全局顶栏、侧栏和字体仍属于 Dice Life；
- [ ] 三个主页面保持统一圆角、阴影和页签样式；
- [ ] 情绪图标为原创资产，名称和图标同时出现；
- [ ] 桌面、平板、移动四档无溢出；
- [ ] 触控目标、焦点、对比度和 reduced-motion 合格；
- [ ] 空状态不出现惩罚、断签或失败表达；
- [ ] 页面中没有社交、评分或竞争性暗示。
