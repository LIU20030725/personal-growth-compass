# 图一情绪表情完整替换实施计划 v1.3.1

**目标：** 将情绪模块现有 18 个 CSS 表情完整替换为用户图一所示的表情造型，同时保留名称、分组、记录数据与交互。

**架构：** `EmotionIcon` 改为自包含 SVG 图谱。所有表情共享圆脸渐变、描边粗细和尺寸规则，每个 mood ID 独立声明眼睛、眉毛、嘴型与装饰，避免不同情绪复用错误五官。外层继续提供现有 class、选中态和 `data-mood-group`，不改调用方。

**技术栈：** React、TypeScript、SVG、Vitest、Testing Library。

映射：

- 开心：弯眼、张嘴、腮红；兴奋：星星眼、张嘴、闪光。
- 感激：闭眼、微笑、腮红、爱心；满足：半垂眼、微笑。
- 平静：圆点眼、微笑；放松：闭眼、微笑、呼气云朵。
- 专注：平眉、圆点眼、横嘴；清醒：大圆眼、横嘴、蓝色感叹号。
- 疲惫：下压眉、哈欠嘴、紫色气泡；无聊：侧视眼、横嘴。
- 低落：忧伤眉、撇嘴；孤独：侧视异向眼、横嘴、紫点；悲伤：忧伤眉、撇嘴、双泪。
- 焦虑：忧伤眉、大圆眼、波浪嘴、汗滴；压力：挤眼、矩形嘴、压力线。
- 生气：怒眉、圆眼、撇嘴、双蒸汽；迷茫：侧视眼、撇嘴、问号；撑不住：挤眼、咬牙、怒符号。
