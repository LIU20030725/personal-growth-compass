# Dice Life 情绪模块精细化更新方案 v1.2

日期：2026-08-12  
来源：飞书《0811-精细化更新各模块》情绪模块章节  
范围：仅情绪模块与必要的模块内存储接口

## 1. 目标

本轮把情绪模块从“可记录”升级为“可回看、可收藏、可提醒、可播放”的私人心情收纳箱，同时收敛编辑器内重复、文字化的选择控件。全部历史记录继续留在本地，首页只承担“最近发生”的轻量浏览，完整历史通过心情日历查找。

## 2. 推荐整合方案

采用“本地优先 + 平台无关音乐引用 + 渐进增强提醒”的方案。

- 情绪记录、重要日、音乐卡片元数据继续保存在 localStorage；图片、视频、录音 Blob 继续保存在 IndexedDB。
- 首页只展示最新 10 条，不删除第 11 条及更早记录；日历、内容库和那年今日仍使用完整数据集。
- 收藏库既收纳文字和媒体，也能收纳一条只有情绪/活动的“时刻”。这样收藏无文字、无附件的记录后也一定有可见结果。
- 音乐先实现标准化歌曲卡片：网易云、QQ 音乐或其他来源均可保存标题、歌手、来源链接；若有浏览器可播放的音频地址则站内播放，否则点击播放会打开原平台。完整曲库搜索、会员歌曲播放依赖平台授权和服务端能力，不在纯前端版本内伪造。
- 重要日先实现本地创建、提前天数、日历星标和应用内到期提示；浏览器关闭后的系统级通知需要后续 PWA/服务端调度。

## 3. 八个修改点

### 3.1 音乐收藏与播放（P1）

范围：新增 `EmotionMusicReference`，每条情绪记录最多关联 1 首歌；编辑器支持填写歌曲名、歌手、网易云/QQ 音乐/其他来源链接，以及可选的可播放音频地址。

交互：详情页与内容库展示封面占位、歌名、歌手和来源；主按钮优先站内播放 `playbackUrl`，没有可播放地址时打开 `sourceUrl`。播放按钮必须明确区分“播放”和“去平台收听”。

数据影响：情绪状态升级到 v2；旧记录迁移时补 `music: []`，不影响现有附件。

风险：网易云与 QQ 音乐没有面向当前纯前端产品的通用公开全曲播放能力。腾讯公开平台主要提供通用应用、社交与内容能力，并不能据此假设 QQ 音乐曲库可直接播放。因此本轮不使用非官方抓取接口，不保存有时效签名的盗链。

### 3.2 收藏后内容库不显示（P0）

根因：当前内容库只从“有文字的日记”和附件派生卡片；一条只有情绪和活动的记录即使被收藏，也不会产生内容库条目。

修改：收藏记录后，只要 `entry.isFavorite=true`，就派生一张 `moment`/日记卡；取消收藏且没有文字时移除该卡。有文字记录仍自动进入内容库。音乐和录音也纳入媒体筛选。

验收：收藏“专注 + 创作、无文字、无附件”后，内容库立即出现该时刻，点击回到原记录。

### 3.3 重要日与提前提醒（P1）

范围：点击“记录感受”先出现底部上拉菜单，提供“记录此刻”和“添加重要日”。重要日包含标题、日期、提前提醒天数（当天/1/3/7/30 天）、备注、是否每年重复。

交互：日历对应日期右上角显示克制的小星星；当天或进入提醒窗口时，日记首页显示安静的提醒条。日期详情可同时看到当天记录和重要日。

数据影响：v2 状态新增 `importantDays`。重要日与情绪记录分表，删除或编辑互不影响。

已知限制：本轮是应用内提醒；关闭网页后不会主动弹出系统通知。

### 3.4 那年今日（P1）

范围：心情日历下方新增“那年今日”，筛选“与今天同月同日、年份早于今年”的历史记录，按年份倒序展示。

边界：闰日记录只在 2 月 29 日出现；不把今年今天的记录混入；点击卡片进入原记录详情。

### 3.5 语音圆形按钮播放（P0）

根因：编辑器和详情页使用浏览器原生 `<audio controls>`，截图中被误认为不可点击的小圆点，且不同浏览器外观不一致。

修改：新增统一的语音播放器，中央圆形按钮负责播放/暂停，旁边显示时长与进度；编辑器待上传语音和详情页已保存语音复用同一组件。保留隐藏 audio 元素负责实际媒体能力。

边界：播放失败时显示可理解错误；对象 URL 在卸载时释放；不回退已有的录音 10 分钟上限和麦克风释放能力。

### 3.6 首页只保留最新 10 条（P1）

范围：日记首页从完整记录中取最新 10 条再按日期分组。第 11 条及更早记录不删除，仍可从日历、内容库、那年今日进入。

文案：列表末尾出现“这里只展示最近 10 条，更多记录请到心情日历查看”。

### 3.7 UI 去重复、收敛层级（P1）

方向：保留 Daylio 式分组、冷白/鼠尾草/柔黄系统；减少大面积重复卡片、过大的表情和同构按钮。编辑器每一阶段只保留一层容器，标题、说明、选项形成清晰节奏。

约束：不覆盖工作区中尚未提交的表情细化稿；新增视觉规则放在独立增强样式文件，并在最终整合时由总控决定是否合并表情稿。

### 3.8 “刚刚在做什么”图形化（P1）

范围：把纯文字 chip 改为与情绪选择一致的“图标 + 文字”网格，仍支持多选、分组、键盘与读屏。图标使用现有 lucide-react，不新增依赖。

交互：选中态使用柔黄底、1px 边界和勾选提示；图标只作辅助，文字始终存在。

## 4. 数据结构

```ts
interface EmotionStateV2 {
  schemaVersion: 2;
  entries: EmotionEntryV2[];
  importantDays: EmotionImportantDay[];
}

interface EmotionEntryV2 extends EmotionEntryV1 {
  music: EmotionMusicReference[];
}

interface EmotionMusicReference {
  id: string;
  provider: 'netease' | 'qq' | 'other';
  title: string;
  artist: string;
  sourceUrl: string;
  playbackUrl: string;
  isFavorite: boolean;
}

interface EmotionImportantDay {
  id: string;
  title: string;
  dateKey: string;
  note: string;
  remindDaysBefore: 0 | 1 | 3 | 7 | 30;
  repeat: 'none' | 'yearly';
  createdAt: string;
  updatedAt: string;
}
```

迁移规则：读取 v1 时原地转换为 v2；旧 key 保持不变以避免遗失数据，下一次保存写入 v2。无法识别的损坏数据继续沿用备份与回退机制。

## 5. 交互流

1. 用户点击“记录感受”。
2. 底部上拉菜单出现：记录此刻 / 添加重要日。
3. 记录此刻进入原编辑器；可选择情绪、图形化活动、文字、媒体、语音和音乐卡片。
4. 添加重要日进入轻量表单；保存后日历星标与首页提醒同步出现。
5. 首页最多展示 10 条；内容库与日历使用完整数据。

## 6. 测试与风险控制

- 存储：v1→v2 迁移、损坏回退、重要日保存失败不污染内存状态。
- 收藏：无文字记录收藏后派生内容库卡片；取消收藏后正确消失。
- 首页：11 条记录只渲染最新 10 条，但日历能找到全部。
- 那年今日：跨年、今年排除、闰日。
- 重要日：一次性和每年重复的日期匹配、提醒窗口、星标。
- 播放：语音播放/暂停、失败提示、对象 URL 释放；音乐站内播放与外链回退。
- 无障碍：新增 dialog 初始焦点、Escape、焦点归还；活动多选保留 `aria-checked`；播放器有明确 accessible name。
- 兼容：不修改现有媒体事务顺序、录音关闭清理、附件编辑删除逻辑。

## 7. 本轮不做

- 不接入非官方网易云/QQ 音乐抓取接口。
- 不承诺会员歌曲或完整曲库站内播放。
- 不实现网页关闭后的系统推送、短信或邮件提醒。
- 不改主应用信息架构、财富/任务/能力模块。
