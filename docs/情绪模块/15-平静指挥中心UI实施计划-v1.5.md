# 情绪模块「平静指挥中心」UI 实施计划 v1.5

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改动情绪模块业务、存储与媒体边界的前提下，把关键旅程重构为低噪音、单主动作、可访问的「平静指挥中心」。

**Architecture:** 由 `EmotionModule` 统一主视图页头、次导航和创建入口；各 view 只负责内容。`EmotionComposer` 通过类别切换减少同时可见选项，但继续提交原有 `EmotionDraft`。样式只在现有 CSS 中建立/复用 token，不新增依赖。

**Tech Stack:** React 18、TypeScript、vanilla CSS、Vitest、Testing Library、Playwright、axe-core。
