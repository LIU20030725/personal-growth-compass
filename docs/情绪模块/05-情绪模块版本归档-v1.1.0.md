# Dice Life 情绪模块版本归档 v1.1.0

> 版本序列：v1.0.0 → v1.1.0
>
> 归档日期：2026-08-03
>
> 开发分支：`codex/emotion-module`
>
> 本次功能最终实现提交：`277b4d3 style(shell): align shared chrome with calm visual system`

## 1. 版本定位

v1.1.0 是情绪模块交付后的共享应用壳层协调版本。情绪记录、媒体、日历和内容库业务逻辑保持不变，本次只调整 Dice Life 顶栏、侧栏、角色入口、英雄属性和共享内容几何，使财富、任务与情绪三个入口处于同一视觉环境。

## 2. 本次变更

- 保留 Dice Life 黄色骰子品牌、像素头像、导航名称和现有信息架构；
- 顶栏与侧栏统一为冷白、极淡鼠尾草层次，边界由 2px 厚线降为 1px 柔和分隔；
- 移除角色卡和英雄属性区域的硬黑阴影与大面积灰盒；
- 角色卡改为 16px 轻容器，像素头像继续使用清晰的品牌黄焦点；
- 英雄属性改为无边框圆角进度条，财富、健康、情绪使用低饱和区分色；
- 顶部与侧边导航选中态收敛为柔黄底、深色文字和细边界；
- 桌面侧栏宽度统一为 240px，主内容从同一几何边界起步；
- 1024px 使用横向模块导航，390px 延续现有移动导航结构，不渲染桌面侧栏；
- 为当前导航目的地补充 `aria-current="page"`；
- 修正任务页紧凑黄色奖励标签的文字对比度，使真实浏览器 axe serious / critical 降为 0。

## 3. 验证证据

### 自动化与构建

- 全量测试：`npm test -- --run`，18 个测试文件、71 项测试全部通过；
- 生产构建：`npm run build` 通过；
- 新增共享壳层回归：验证 calm shell 标记、当前导航语义及入口切换；
- 原有财富、任务、情绪导航、焦点、媒体与弹窗测试均保持通过。

### 真实浏览器

- 财富、任务、情绪三个入口均完成 1440×900、1024×768、390×844 截图；
- 九个页面均无横向溢出；
- 1440px：侧栏 `0–240px`，三个入口主区域均从 `240px` 开始；
- 1024px：共享导航位于 `64–136px`，财富与任务内容保留 20px 外边距，情绪背景保持全宽、内部内容独立对齐；
- 390px：共享导航位于 `64–134px`，使用可横向浏览的现有移动模块导航；
- 真实 Chromium axe：财富、任务、情绪 serious / critical 均为 0。

## 4. 已知限制

- 本版本严格限定共享应用壳层，财富与任务模块内部仍保留各自原有的硬边框视觉语言，未在本次跨范围重构；
- 390px 模块导航沿用横向滚动结构，当前项会优先保持可见，左右部分入口可能需要横向滑动查看；
- 任务模块仍存在 axe 的非 serious/critical landmark 提示，涉及模块内部主区域语义，本轮未修改任务业务组件；
- 截图与 axe 证据来自本地 Chromium；iOS Safari、Android Chrome 的系统字体缩放和真实触控仍需发布前真机复核；
- 本次未新增设计系统依赖、未修改导航信息架构、未 push 或合并 `main`。

## 5. 发布结论

v1.1.0 已完成情绪模块与共享 Dice Life 壳层的视觉衔接。共享导航保持品牌辨识度，桌面、平板与手机几何稳定，自动化、构建和 serious/critical 无障碍门禁均通过，可由主控复核后统一推送。
